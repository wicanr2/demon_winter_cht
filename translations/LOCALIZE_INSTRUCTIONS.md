# 遊戲內文字翻譯指令

> 翻 `assets/lang/zh-Hant/*.txt` 的人（含 subagent）**動手前先讀完這份**。
> 多人／多 agent 分頭翻同一批文字，最容易壞在譯名與語氣各自發揮 ——
> 這份指令存在的唯一目的就是擋住那件事。

## 0. 先讀

- **譯名一律查 [`glossary.md`](./glossary.md)**，那是全專案唯一的譯名真相來源。
  表裡沒有的詞：先加進表再用，不要臨時自創。
- 1990 年軟體世界譯本的譯名見 [`../docs/manual-cht/03-translation-1990.md`](../docs/manual-cht/03-translation-1990.md)。
  那是史料，**不是可以直接抄的來源** —— 已知有誤譯，且同一本書內部就不一致。

## 1. 檔案格式

```
## 12            ← 記錄索引，不要改
:: en            ← 原文區塊，一個字都不要動
A group of followers yell 'Glory to Xeres' and attack.
:: zh            ← 譯文寫這裡
一群信徒高喊「澤瑞斯萬歲」，向你們撲來。
```

`:: en` 是引擎的查核依據。改到它，載入時會判定「翻譯檔與資料脫節」
而**整條退回英文**，等於白翻。

`!! ` 開頭的那行代表原文變動過、譯文要複查；複查完把那行刪掉。

## 2. 硬規則

1. **`:: en` 區塊一字不動**，包含拼字錯誤（原版就有錯字，照留）。
2. **控制序列原樣保留**：`%s`、`%d`、`%3d` 的**數量與順序**要跟原文一致。
   中文語序不同時，移動它們的位置沒關係，但不能增刪。
3. **只用 Big5 打得出來的字。** 字型是倚天點陣，Big5 以外的字沒有字模，
   畫面上會變成空白。常見地雷：簡體字、日文漢字（塁、뿔）、`é`、`・`。
   自動檢查：`tools/go.sh run ./cmd/dwstrings check`。
4. **長度控制在原文的 ±40% 以內**（以顯示格數估：一個中文字 = 兩個英文字母寬）。
   一頁只有 5 行 × 38 格，超過就要多翻一頁，破壞原本的節奏。
5. 空的 `:: zh` 代表還沒翻，是合法狀態 —— 引擎會顯示英文原文。
   **寧可留空，也不要交半通不通的句子。**

## 3. 語氣

這是 1988 年的美式 CRPG 地城敘述，第二人稱、簡潔、略帶陰森。

- 敘述句用**現在式的白話中文**，不要文言（「汝見一骷髏」✗ →「你看見一具骷髏」✓）。
- 不要加原文沒有的情緒與形容詞。原文說 `Two guards are in the room`
  就是「房裡有兩名衛兵」，不是「兩名彪形大漢惡狠狠地擋在你面前」。
- 原文的引號內容（咒語、銘文、喊話）照譯，保留引號。
  拉丁文銘文（如 `Gloriosus victime`）**不譯**，保留原文並可加中文注。
- 原文缺句號的地方（原版常見）照補中文句號，不必刻意保留缺漏。
- 全形標點：中文用「」，不要用 ""；逗號用 `，`，不要用 `,`。

## 4. 交件前自己過一遍

- [ ] 每個 `:: en` 區塊與原檔逐字相同
- [ ] 專有名詞全部對得上 `glossary.md`
- [ ] 沒有簡體字、沒有 Big5 以外的字
- [ ] `%s`／`%d` 數量與原文一致
- [ ] 沒有「你將會發現」「令人不禁」這類原文沒有的贅語
