# Research PC-98 Golden Box UI

Use PC-98 Golden Box ports as comparative evidence for fitting CJK text into Western
party-based CRPG interfaces. Treat them as layout references, never as the behavioral
oracle or a source of reusable copyrighted art.

## Knowledge-base loading contract

Keep this skill as the keyword-triggered entry point. Do not add its detailed research
to global startup instructions or read the reference for unrelated sessions.

- For a Golden Box or CJK layout task, load only the linked reference sections needed
  for that screen type or measurement.
- For a complete cross-screen audit, read the full reference once after this skill
  triggers.
- Keep project-specific findings in the project repository; promote only reusable,
  cross-title evidence into this knowledge base.

## Workflow

1. Identify the screen type: exploration, dialogue, combat, camp, shop, character
   creation, automap, or full-screen narrative.
2. Read [references/layout-patterns.md](references/layout-patterns.md) for the baseline
   corpus, measurement conventions, established patterns, and source links.
3. If current screenshots or precise attribution matter, browse the linked galleries
   and verify the game, platform, native resolution, and screen type. Cite the pages
   used. Do not rely on search thumbnails as evidence.
4. Compare equivalent screen types, not unrelated scenes. Separate observations into:
   measured fact, cross-title pattern, design inference, and project-specific decision.
5. Produce a compact audit covering canvas, font cell, line height, text capacity,
   information regions, color roles, input prompts, and overflow behavior.
6. Preserve the target game's rules, content hierarchy, and visual identity. Recommend
   structural patterns; do not copy logos, frames, portraits, sprites, or wording.
7. Validate at native resolution and with the densest realistic CJK strings. Theme
   changes must not alter wrapping, selection, layout geometry, or game state.

## Evidence discipline

- Prefer multiple titles from both Dragonlance and Forgotten Realms before calling an
  observation a Golden Box pattern.
- Record native pixels. Screenshot viewers often apply nearest-neighbor enlargement.
- Mark approximate measurements and allow about one native pixel of gallery-preview
  error unless the original image file was inspected.
- Treat PC-98 palette choices as inspiration for a modernized theme, not evidence for
  the original DOS EGA/CGA palette.
- Apply Chinese punctuation compression and line-breaking rules independently; Japanese
  screenshots do not prove Traditional Chinese kinsoku behavior.
- Keep bitmap fonts at integer scale and disable filtering during parity comparison.

## Expected output

Include:

- titles and equivalent screens examined;
- source links and native resolution;
- a measured comparison table;
- patterns safe to adopt;
- project-specific choices to retain;
- copyrighted details not to copy;
- native-resolution acceptance checks.

For a quick design decision, read only the reference sections relevant to the requested
screen. For a full UI audit, read the entire reference.
