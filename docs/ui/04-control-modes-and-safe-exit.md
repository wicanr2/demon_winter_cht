# 操作模式、F1 說明與安全離開

日期：2026-07-29  
狀態：操作輸入、兩套命令介面與安全離開均已實作；待使用者畫面審查

## 產品目標

重製版同時照顧兩種玩家：熟悉 1980 年代相對轉向的人，可以保留肌肉記憶；
第一次接觸《冬之魔》的人，也不必先學會老式鍵盤慣例。兩套操作只翻譯輸入，
不能分叉碰撞、時間、事件、背後攻擊、海戰或存檔規則。

## 已定案行為

| 功能 | 現代模式（預設） | 復古模式 |
|---|---|---|
| 探索移動 | 四方向鍵朝絕對方向轉向並前進 | `←/→` 原地轉向；`↑` 或 `Enter` 前進；`↓` 轉身 |
| 命令介面 | 兩欄卡片，以「常用／探索／物品／系統」tab 式標題分組 | 原版紅底單一直式命令列與棋盤網點停用狀態 |
| 即時切換 | `F6` 在兩模式間切換，狀態列顯示結果 | 同左 |
| 啟動選擇 | `-controls modern` | `-controls retro` |
| 海戰 | 維持原版相對轉舵、直行與點數成本 | 同左，不受探索偏好影響 |

切換操作模式不移動隊伍、不改面向、不重擲亂數，也不寫入原版相容存檔欄位。
這避免為偏好設定發明不存在的 legacy byte；後續若要記住偏好，應使用獨立設定檔。

### 命令區不是把按鈕塞成一條

現代模式將右欄完整 320 px 寬度分為兩欄。每個語意群組都有 tab 式標題、獨立
底色、按鈕邊框與固定欄距；世界探索分為「常用／探索／物品／系統」，營地、
城鎮與戰鬥使用各自的語意分組。功能仍保留原熱鍵，停用條件亦與復古模式共用
同一批 `MenuItem`，不會因換皮得到不同規則。

復古模式則刻意不使用這套卡片：它回到原版紅底單一直式命令列、黑字、列分隔線
與約 50% 棋盤網點。也就是 `F6` 切換的是整套操作介面，不只是方向鍵。

## F1 永遠是說明

`F1` 現在由最外層輸入分派處理，探索、城鎮、地城、戰鬥等畫面都能暫停原狀
開啟手札，`Esc` 關閉後回到原畫面。舊 `F2` 暫留為相容別名，但公開介面只標
`F1 說明`。原先占用 `F1` 的就地建角捷徑已下架；建角仍由正常新遊戲流程與
明確的開發旗標進入，不再污染玩家按鍵。

## 關閉即自動存檔

`F10` 既有確認框與視窗關閉鈕都使用 `writeSave()`，因此會一起保存：

- 隊伍、位置、面向、時間、金幣與裝備；
- `nSS.DAT` 一次性事件／劇情格狀態；
- `ITEMLOCB.DAT` 地城道具位置；
- 已被遊戲改寫的地圖狀態。

視窗關閉使用 Ebiten 的 handled-close 流程：寫入成功才結束；任何一步失敗都留在
遊戲並顯示「自動存檔失敗，沒有關閉」。這是失敗即關閉（fail-closed）原則，
避免關閉鈕成為無聲丟進度的旁路。`F10` 仍保留 `N` 不存檔離開，讓玩家可明確
放棄本次變動。
