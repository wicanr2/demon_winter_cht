> 狀態：**READY**（`OPEN.PIE` 未解，但有 CGA 版可替代，不擋開工）

> 最後複核：2026-07-25（清掉該文 §6／§8 兩處過時斷言）

---

## 行為

遊戲有 CGA 與 EGA 兩套完整素材，開機時以 `INT 10h` 偵測顯示卡後擇一載入
（判別旗標 `DAT_31f0_19fb`：`0` = CGA、非 `0` = EGA）。

兩套素材內容相同、佈局不同。**兩套都要支援** —— 這是文化保存的完整性要求，
不是二選一。

## 演算法

### CGA 全螢幕圖 `.PIC`

```
320 × 200，2bpp，**線性排列**
每列 320/4 = 80 bytes，每 byte 4 個像素，MSB-first
調色盤 = CGA palette 1 高亮度：{黑, 亮青, 亮洋紅, 白}
```

> **不是** IBM CGA 硬體 framebuffer 的偶／奇掃描線交錯佈局。
> 這點只有肉眼比對抓得到 —— 兩種佈局的位元組數完全相同。

### CGA 精靈圖 `.SHP`

frame **16 寬 × 32 高**。注意**不是 32×16** —— 位元組數相同，靠肉眼比對定案。

### EGA 全螢幕圖／人像框 `.PIE`

```
檔頭 16 bytes = 內嵌調色盤
之後 4 個 plane 依序排列（sequential，不是列內交錯）
MSB-first
高度是 CGA 版的 1.75 倍（144 → 252）
```

### EGA 精靈圖 `.SHE`

```
frame 32 寬 × 28 高，448 bytes/frame，4-plane，無壓縮
frame 內位移 = row × 16 + plane × 4 + col
```

> **`.SHE` 是 32×28，不是 16×56。** 從 CGA 的 16×32 套「高度 ×1.75」會推出 16×56，
> 總像素數與 32×28 相同，**算術完全分不出來**。實際是「寬度加倍、高度略減」，
> 與直覺相反。指令級證據：`217b:07e6 MOV CL,0x1c`（28 列）、
> `217b:0810 MOV CX,0x1c0`（stride 448）。
>
> `CYPHER.SHE` 的 frame 是 224 B，同公式外推為 16×28 可得乾淨結果，
> 但 `07cf` 的 stride 寫死 448、未直接涵蓋這個檔，**標假設**。

EGA 寫入走 sequencer map mask（port `0x3c4`/`0x3c5`），目標畫面 640×350 十六色。

### 3.5 倍規律的正確用法

`3.5 = 2（2bpp→4bpp）× 1.75（高度）`。這個分解**只約束總位元數**，
`.PIE` 人像框與 `.SHE` 精靈圖的檔案大小都符合。

**但它推不出佈局。** 本專案在這上面踩過四次（見 `CONTEXT.md` §5 陷阱 ②），
其中三次的錯誤版本都能通過全部自動測試。

> **硬性驗收條件：任何視覺產物一律 dump 成 PNG，肉眼比對 DOSBox 原版截圖。**
> 不接受「解碼器沒報錯」或「測試綠」當作正確的證據。

## 邊界條件

| 情況 | 行為 |
|---|---|
| CGA/EGA 判別 | `DAT_31f0_19fb == 0` → CGA；非 0 → EGA。開機時以 `INT 10h` 決定 |
| `.PIE` 調色盤 | 每個檔自帶 16 bytes，不共用全域調色盤 |
| `CYPHER.SHE` | frame 224 B（其餘 `.SHE` 是 448 B），需特判 |

---

## 驗收

1. **逐檔 dump 比對**：每個素材檔解碼成 PNG，與 `workplace/dosbox/shots/` 的
   原版截圖肉眼比對。**這是硬性條件，不可用測試綠替代。**
2. **CGA/EGA 交叉一致性**：同一張人像框的兩個版本解碼後，圖案內容必須一致
   （只有色深與高度不同）。
3. **`OPEN.PIC`**：解出的畫面必須能看出魔鬼臉孔、`DEMON'S WINTER` 標題、
   `NOVOTRADE` 與 `STRATEGIC SIMULATIONS INC` 商標、下方製作人員名單。

## 未解 / 風險

| 項目 | 影響 |
|---|---|
| `OPEN.PIE`（102,160 B）| 唯一未解的素材。不符 3.5× 規律，六種候選尺寸全是雜訊。**不擋開工** —— 開場畫面可先用已驗證的 CGA `OPEN.PIC`。但依完整性原則，這項必須補上，不得以「只是開場畫面」為由跳過 |
| `CYPHER.SHE` 的 16×28 | 同公式外推可得乾淨結果，但 blit 的 stride 寫死 448，未直接涵蓋。標假設 |
| 中文化的畫布尺寸 | 規劃拉到 640×400（中文需 16×16 點陣才可讀，英文 8×8 放大兩倍後同高）。見 `09-fonts.md` |
