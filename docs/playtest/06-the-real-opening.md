# 06 — 前四輪都從遊戲中段開始玩

`docs/playtest/05` 的下一步寫「建角開新遊戲還沒進試玩流程」。
去接的時候發現的不是「缺一個建角流程」，是**前四輪的起點根本不對**。

---

## 1. 出貨的 `PARTY.DAT` 是玩過的存檔

完整證據在 `docs/re/87`。摘要：建角程式（`0x148c8`–`0x1497f`）寫死了
起始值，跟出貨存檔**九個欄位不同** —— 最關鍵的是地圖，
`1`（地城）vs `34`（世界地圖）。

**線索早就在第一張截圖裡**：`docs/playtest/01` 的戰鬥畫面上
Menhir 的血是 15/27。剛建好的隊伍不會帶傷。
我當時把它當成「原版就是這樣出貨」，沒有追 ——
而 `docs/re/78` §2 明明記過同一組出貨資料的另一半也是髒的
（`1SS`／`2SS` 帶著 29 處遊玩痕跡）。

> **同一份出貨資料裡有一個檔案是髒的，其他就都要懷疑。**
> 這是這一輪最貴的教訓：四輪試玩、五篇文件，
> 全部建立在一個沒有被驗證過的前提上。
> 前面的觀察沒有錯（走了幾步、觸發了什麼都是真的），
> 但**它們描述的不是玩家會經歷的開場**。

## 2. 順帶炸出一個被巧合掩蓋的 bug

引擎載哪張地圖，看的是 `-map` 旗標，**完全不看存檔的 MapID**。

`-map` 預設是 `MAP1.MAP`，出貨存檔剛好是圖 1 —— **兩者一致純屬巧合**，
所以這個洞一直沒被發現。接上 `-newgame` 才炸：座標套用了 (28,50)、
地圖還是圖 1，隊伍站在另一張圖的同一組座標上，走兩步撞牆。

**畫面上完全看不出是哪一張圖。** 只有軌跡的第一行寫著
`啟動：地圖 1，隊伍在 (28,50)` —— 兩個數字擺在一起才看得出矛盾。

修法：`-map` 預設空字串 ＝「用存檔的地圖編號」，而且地圖要在
存檔（含 `-newgame`）決定之後才載。

## 3. 真正的開場

```
   1  啟動：地圖 34，隊伍在 (28,50)，5 人
   3  野外  (28,50) 地圖34
   ...
  11  城鎮  (31,45) 地圖34  訊息="進入海濱鎮"
```

**5 時 8 日紅玉月，海邊的草原上，面向東，75 金、20 份糧食。**
往西北走八步就是**海濱鎮**（物價指數 10，有市集／治療所／旅店／神殿／酒館）。

這才是 1988 年 CRPG 該有的開場：先進城補給，再決定往哪走。
地城在 59 步之外。

從起點走得到的東西（`dwroute` 逐點測距）：

| 目標 | 步數 |
|---|---|
| **海濱鎮 (31,45)** | **8** |
| 學院 (18,48) | 12 |
| 城鎮 (46,45)／出口 → 圖 2 | 23 |
| 學院 (49,40) | 31 |
| 出口 → 圖 1（地城）| 59 |
| 其餘三座城鎮、兩座神殿、一座學院 | 61–102 |

對照前四輪：從地城 (9,32) 出發，**走得到的出口只有一個**，
而且要在圖 1 與圖 34 之間來回穿梭兩次才出得去
（`docs/playtest/05` §3）。那條路線的怪異形狀現在有解釋了 ——
**它是從地城中段往外走才會遇到的形狀。**

## 4. 這一輪沒做完的

`-newgame` 只設隊伍共用欄位（位置、時間、金幣、糧食、船、陣型），
**五個角色仍然是出貨存檔那五個**。真正的「建角開新遊戲」還要串：

- 開新遊戲時強制走五次建角（`createui.go` 已經是覆寫槽位的形式，
  所以機制在，缺的是流程與「五個都建完才能出發」的閘門）。
- 建完之後的角色狀態要對得上原版建角程式寫的那些角色欄位
  （本篇只掃了 trailer 的隊伍共用欄位，角色記錄還沒逐一比對）。

在那之前，`-newgame` 的價值是**起點對了** ——
之後所有試玩都該從這裡開始，而不是從地城中段。
