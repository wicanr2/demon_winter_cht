# 04 — 走出地城的第一格就是一座神殿

`docs/playtest/03` 讓隊伍走出了地城，落在地圖 34 的 (55,8)。
下一步理當是「地面上有什麼」—— 而答案很直接：**落點那一格就是一座神殿。**

在此之前，世界地圖上的神殿與學院都只印一行
「（世界地圖上的設施還沒接）」。這一輪接上了（`docs/re/86`）。

---

## 1. 驗證：從地城走到神殿裡

零捷徑（只有 `-autofight`），從原版出貨存檔開始：

```
  33  野外  (22,20) 地圖1
  34  換地圖 → 34 (55,8)
  35  野外  (55, 8) 地圖34  訊息="進入地圖 34 的 (55,8)"
  36  野外  (54, 8) 地圖34
  37  城鎮  (55, 8) 地圖34  訊息="進入Gamur的神殿"
```

第 36–37 行是**踩下去再踩回來**：換地圖用的是傳送，所以落地那一瞬間
不會觸發原地的地點（`docs/re/85` §4 記過這個設計）。往西走一步再走回來，
神殿就開了。

畫面上五名隊員都在，祈禱／捐獻／改宗三項服務都出得來，
神祇名字是 **Gamur** —— 從 `FILES.DTT` 的神祇名表讀出來的，
不是「神祇 3」那種越界的樣子。

## 2. 學院：(46,7) 的觀地學院

世界地圖上走不過去（西邊是山），`tools/route.py` 也還不會在
`SUM.MAP` 的段上找路（見 §4），所以用 `-map 34 -x 47 -y 7` 起始，
往西一步踩上去：

```
   4  城鎮  (46, 7) 地圖34  訊息="進入觀地學院"
```

**三個數字互相對得上**：`docs/re/74` #12 是 (46,7) 觀地、
我從 `DEMON.INT` 重抄的表第 12 筆技能欄是 26（觀地）、
畫面上的學費是 750 金 ＝ `CollegeGoldCost(10) = 10*(5*10+25)`。

## 3. 一個順手修掉的介面錯

第一版的神殿畫面底下寫「Esc：回到設施選單」——
那是城鎮畫面的字，而世界地圖上的設施**只有一項**。
按下去會退到一個只有一項的清單，看起來像卡住了。

加了 `townScreen.worldSite` 旗標：地圖上的設施 Esc 直接回地圖，
提示改成「Esc：離開」。

> 這是「重用現成畫面」的代價：省下四種服務的實作，
> 換來一處**文案假設不成立**。省得值得，但要把不成立的地方找出來 ——
> 而找出來的方法是把它跑起來看，不是讀程式碼。

## 4. 工具的缺口

`tools/route.py` 只吃獨立的 `MAPn.MAP`，**不會處理 `SUM.MAP` 的段**
（世界地圖與地圖 2、4 都在裡面）。

沒有順手補上，理由是：`SUM.MAP` 是 RLE 壓縮的，Python 這邊要再寫一份
解壓 —— 而**兩份解壓實作遲早會不一致**，那時候「路規劃錯了」
與「解壓錯了」分不開。真要補的話應該是從 Go 那邊 dump 出未壓縮的段，
不是重寫解壓。

在補上之前，世界地圖上的移動驗收只能靠手寫按鍵序列 + 軌跡核對。
