# 音效觸發收尾（2026-07-30）

## 範圍裁決

DOS 執行檔沒有背景配樂，也沒有 AdLib／MIDI 呼叫。原版聲音庫只有八個
PC speaker 單音（effect 1–8，C3–C4）與死亡短旋律（effect -1）。
因此「音樂還原」的完成定義是死亡旋律，不另創背景音樂。靜態證據與
逐 byte 音符表見 [`docs/re/03`](../re/03-audio-and-resources.md)。

## 本輪補齊的呼叫端

| 情境 | 原版證據 | 重製版 |
|---|---|---|
| 怪物攻擊未命中 | 攻擊者槽位 `< 7` → effect 1 | `EffectC3` |
| 玩家攻擊未命中 | 攻擊者槽位 `>= 7` → effect 4 | `EffectF3` |
| 武器類型 2／11 命中 | `unit+0x24` 為 2 或 `0x0b` → effect 5 | `EffectG3` |
| 其他武器命中 | 上述條件不成立 → effect 8 | `EffectC4` |
| 戰鬥行動點不足 | action case 共用 effect 2 | `EffectD3` |
| 密語答對 | 兩個正解分支皆呼叫 effect 8 | `EffectC4` |
| 恆世寶珠尚不可取／已取 | 兩道閘門皆呼叫 effect 4，無文字 | `EffectF3` |
| 單位死亡 | effect -1 | `EffectDeath` |

攻擊分支以純函式測試釘住怪物／玩家及正負武器索引；帶毒武器先取絕對值，
與規則層解碼一致。行動點不足統一經 `reportNoAP`，避免施法、召喚與特殊動作
各自漏播。

## 保守邊界

世界撞牆、船隻撞岸雖已確認「會有聲音」，既有研究尚未把所有呼叫點的
effect 編號可靠地對回情境，因此本輪不猜音高。這不影響已解出的完整聲音
素材庫，但呼叫端仍標為未知，而不是假裝與原版一致。
