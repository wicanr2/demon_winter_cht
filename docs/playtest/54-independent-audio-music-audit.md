# 音效／音樂獨立稽核

日期：2026-07-30  
執行者：依使用者要求，由獨立 subagent 評估；主代理未代作結論

## 結論

> 本節保存第一次獨立稽核當下抓到的問題；它不是目前版本的完成度結論。
> 修正後又由另一個獨立 subagent 重驗，最新裁決見「修正後獨立重驗」。

第一次稽核時，音樂範圍已釐清，音色與序列合成已完成；當時**音效觸發尚未
閉合，不能稱為全部完成**。

- 原版 DOS 沒有背景配樂、AdLib 或 MIDI；唯一多音符內容是約 1.5 秒的死亡
  短旋律。因此忠實還原不需要另加 BGM。
- PC speaker 的八個單音與死亡旋律皆已合成，相關 Docker 測試通過。
- 命中、未命中、行動點不足、密語、恆世寶珠、船撞岸及部分戰鬥死亡已接。
- `battleui.go` 的怪物噴吐只要有命中就播放 `EffectDeath`，即使無人死亡；
  原版證據指向吐息／扣血用 effect 8，死亡才用 -1。這是已確認錯誤。
- 世界、陷阱、飢餓、毒、壓牆、海難等非戰鬥全滅共用的
  `checkPartyDeath()` 沒有播放死亡旋律；仍須逐一核對原版死亡呼叫端。
- effect 3／6／7 已合成與預載，但遊戲端沒有呼叫；可能是原版交叉引用尚未
  找全，不能以「庫內存在」冒充觸發完成。
- 既有 A6 皆以 `-volume 0` 執行，沒有實際可聽或錄音驗收證據。

## 建議完成順序

1. 修正噴吐音效，並裁決同一吐息造成多人死亡時的單聲道播放語意。
2. 逐一清查死亡處理的原版交叉引用與 remake 的十一個呼叫端。
3. 加入可注入的音效接收器，以 spy／表格測試驗證 effect ID、靜音與重播。
4. 以 `dwsound` 產生九個 WAV 作頻譜、時長與耳聽驗收。
5. 在有音訊裝置的環境錄下固定場景：未命中、命中、AP 不足、單位死亡、
   密語、寶珠、撞岸與非戰鬥死亡。

在上述項目完成前，公開狀態應寫成：「音色／序列完成，已知觸發多數接上；
觸發閉合與動態聽測未完成。」

## 後續處置

獨立稽核之後，主代理以 IDA 9.4 補完 14 個直接 XREF 清冊並修正程式：

- 吐息已改為無死亡播 effect 8、真的死亡才播死亡旋律；
- effect 3／6／7 已證實是原版庫內未使用音階，不虛構呼叫端；
- 非戰鬥全滅已證實原版不播死亡旋律，不修改；
- 新增可注入 `soundOutput` spy 與吐息三分支測試；
- 播放器會先停止其他 effect，維持原版單聲道；
- 九個 WAV 已輸出至 [`docs/audio`](../audio/) 供人工試聽。

原版證據與可重播 IDA 命令見
[`docs/re/117`](../re/117-audio-xrefs-and-breath-correction.md)。頻率、時長、WAV
生成與全套測試已通過；最後的人耳主觀試聽仍留給使用者，不由代理冒充。

## 修正後獨立重驗

第二個獨立 subagent 對目前版本作唯讀重驗，未沿用第一次稽核的完成宣稱：

- IDA 9.4 重跑仍為 14 個直接 XREF，與 `docs/re/117` 清冊一致；
- 九份 WAV 可由 `dwsound` 逐位元組重建，皆為 44.1 kHz、16-bit、單聲道
  PCM，峰值約 −6.02 dB，沒有靜音檔；
- 攻擊四分支、吐息致死／非致死／免疫、撞岸與切換抽樣通過；
- 沒有發現重大或阻斷性功能缺陷。

最新結論是：**可宣稱音訊技術實作完成；玩家聽感與三平台真實音效裝置驗收
未完成。** 現有 spy 只直接測 `playSound`，沒有涵蓋每條完整 UI 呼叫鏈；
真實播放完成、Sound off、舊音中斷與跨平台出聲仍需動態／人工驗收。

## 使用者驗收

2026-07-30 使用者回覆「音樂 ok」。原版沒有背景 BGM，音樂性內容只有死亡
短旋律；結合前述九份 WAV 技術重驗，本專案音訊產品項正式核准。跨平台真實
裝置能否出聲仍由各平台候選包的實機回報持續監測，不再列為 remake 結案阻擋。
