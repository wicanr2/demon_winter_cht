# 16 — Modern EGA B 方向直接縮圖反證

日期：2026-07-29。

## 1. 問題

M0 的 B 方向稿在放大的 contact sheet 裡較清楚，但這不能證明它能直接成為
32×28 runtime tile。本輪刻意走一條最短、也最容易失敗的路，確認是否能省略
逐格像素重畫：

1. 用 `tools/modernpreview` 在 `workplace/dump` 匯出完整控制組 theme；
2. 把 B 方向稿的七個代表格以最近鄰強制壓成 32×28；
3. 只覆蓋已由原版 atlas 目視確認的少數 DEMON／WINTER 索引，包括森林、深水、
   岸線、隊伍、平原、城鎮與山；
4. 透過正式 `-modern-theme-dir` manifest loader 進遊戲截取世界地圖。

完整臨時 atlas 含使用者自備原版素材的衍生像素，只作本機測試，不提交、不打包。

## 2. 實機結果

![B 方向直接縮圖的失敗實機試片](../design/img/modern-ega-b-direct-downscale-failed.png)

畫面在真正的 9×9 tile viewport 裡暴露三項 contact sheet 看不出的缺陷：

- **岸線不連續**：概念圖的一格海岸不具備原版各方向／轉角的鄰接語意，套到
  多個索引後立即產生斷邊。
- **平原形成重複噪音**：每格相同的高亮草點在平鋪後比隊伍圖示更搶眼。
- **角色失去份量**：直式概念角色被壓入橫式格後過小，anchor 與原版世界圖示
  不相稱。

因此「B 方向稿直接縮圖」判定為失敗；這張截圖只作反證，不是候選宣傳畫面。

## 3. 製作裁決

保留 B 的低紋理、大形與冷暖色方向，但 M1 runtime 素材必須：

1. 以每個原版 index 的 32×28 輪廓為語意參考，逐格手工像素化；
2. 海岸各方向與轉角分開繪製，四邊做 continuity 檢查；
3. 平鋪地形使用低頻、可接邊的紋理；
4. 人物先比對 1-bit silhouette、朝向與 anchor，再加三階明暗；
5. 只把單一新 frame 放回對應索引，不拿一張概念圖代替多個語意。

## 4. 清理

臨時完整 theme 位於 `workplace/dump/modern-b-runtime-trial`，驗收後必須整目錄
刪除。版控只保留失敗截圖、裁決與可重跑的匯出工具；不保存任何衍生原版 atlas。
