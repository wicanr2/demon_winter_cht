# 11 — A6 第一段：新遊戲走到買船的城鎮，順手挖出「法力永遠是 0」

`docs/playtest/10` 把路走通了。這一篇是 A6 的第一段實跑：
**新開檔 → 建五個角色 → 陸路 101 步走到新格里昂**（賣船的城鎮之一），
全程不用 debug 捷徑。

---

## 1. 這一段為什麼是第一段

買船是主線的前置條件（`docs/playtest/10` §5.1：沒有船只到得了 4 張子地圖）。
五座賣船的城鎮與價錢：

| 城鎮 | 座標 | 子地圖 | 經濟係數 | 船價 |
|---|---|---|---|---|
| Janthrin | 57,22 | — | 10 | 570 |
| **新格里昂**（New Gleon）| **34,11** | **44** | 13 | **610** |
| Dragontooth | 51,40 | — | 20 | 670 |
| Asaht | 39,40 | — | 9 | 680 |
| Land's Edge | 41,52 | — | 12 | 600 |

船價 ＝ 城鎮表 `+0x1f5` × 10（`docs/re/19` §4.2）。

挑新格里昂的理由不是最便宜，是**它在陸路走得到的兩張圖之一**（子地圖 44）。
攻略也指名這一座（「前往東北方很遠的新格里昂，買一艘船」）——
兩邊獨立對上。

路線：`dwroute -world -from 34:28,50 -to 44:34,11` → **101 步、跨圖 1 次**。

## 2. 腳本踩到的坑：數字鍵是 1-based

第一版建角段寫 `key 0` 想選人類，結果**只建出三個角色，而且沒有任何錯誤**。

`pressedDigit()` 把 `1`–`9` 對到 `0`–`8`，`0` 回傳 **9**。
種族只有五個，`9 >= 5` → 那一格靜默不動作，於是後面五個按鍵
（Return／Return／名字／Return／Return）全部落到還停在種族階段的畫面上。

軌跡看起來是「第 1 位叫 c」—— 名字對不上、人數少兩個，但沒有一行寫著出錯。

> 這是 `tools/playthrough.sh` 開頭記的那個坑的另一種形狀：
> **按鍵落到別的畫面上不會報錯，只會讓後面的操作意義全變。**
> 抓到它靠的是軌跡裡的名字，不是截圖 —— 截圖上五個槽位看起來都有人
> （另外兩個是出貨存檔留下的角色）。

## 3. 真正的收穫：施法職業的法力永遠是 0

隊伍建好看名冊：**牧師 0／0、術士 0／0，只有巫師 12／12。**
法力是 0 的施法者什麼都放不出來。

`internal/game/create.go` 的 `initialSP` 原本是：

```go
switch class {
case gamedata.Wizard:
    return intellect
default:
    return 0
}
```

註解寫得很清楚：「只有巫師與遊俠有實測依據，其餘職業未測，給 0 ——
猜一個公式會讓『這個值哪來的』變成日後查不出來的謎。」

**那個保守值把主線擋住了。** 破關要 120 點法力（解咒 ×3 各 50、禁錮 100），
一支隊伍只有一個人有法力，怎麼練都湊不到。
而它不會報錯、不會有紅字 —— 只會讓某條路走不完。

### 原版怎麼決定的

建角尾段 `0x14f00`–`0x14f88`：

```
14f25  [+0xfc] = [+0xfa]      ; 生命上限（含加成）← 耐力
14f3b  [+0xfd] = [+0xfa]      ; 目前生命          ← 耐力
14f40  cmpw $0x2,-0x2(%bp)
14f44  jle  14f88             ; 職業 ≤ 2 → 法力三欄一個都不寫
14f57  [+0xfe] = [+0xf9]      ; 法力上限（含加成）← 智力
14f6d  [+0xff] = [+0xf9]      ; 目前法力          ← 智力
14f83  [+0xea] = [+0xf9]      ; 法力上限（天生）  ← 智力
```

`-0x2(%bp)` 是職業：它是上面那段選單迴圈的回傳值減 1（`0x14efb` 的 `decw`
—— 選單回 1-based），而 `0x14f0f` 把同一個值寫進職業欄 `+0xf6`。
`+0xf9` ＝ 智力、`+0xfa` ＝ 耐力兩個對照獨立於本篇（`docs/re/89`、
`docs/spec/05-character.md` 的升級公式）。

**規則是單一個 `> 2` 的比較，不是逐職業的白名單：**

| 職業索引 | 職業 | 初始法力 |
|---|---|---|
| 0–2 | 遊俠／聖騎士／蠻族 | **0** |
| 3–9 | 武僧／牧師／**盜賊**／巫師／術士／靈視者／學者 | **＝ 智力** |

**盜賊也有法力。** 舊註解裡的推測是「依該職業是否天生具備符文／吟唱魔法
決定」—— 那個推測會把盜賊排除掉，而原版沒有這個白名單。

### 修完之後

| 角色 | 職業 | 法力 |
|---|---|---|
| a | 遊俠 | 0／0 |
| b | 聖騎士 | 0／0 |
| c | 牧師 | 7／7 |
| d | 巫師 | 12／12 |
| e | 術士 | 13／13 |

1 級全隊 32 點。升級的 SP 成長是 `max(兩次 Roll(智力/2+1))`，
三個施法者練下去湊得到 120。
