# 4. 附魔（ENCHANTING）

附魔要到矮人工坊（Dwarven Workshop）辦理，位置在遊戲世界西側、長滿葛藤的那塊大陸上。規則如下：

(1) 所有道具（武器、護甲、其他物品）都能附魔賦予賦能力量（invoked powers）。

(2) 賦能力量的運作方式有三種：

- (i) 充能次數（charges）：用完就壞掉，目前沒找到重新充能的辦法。
- (ii) 每日次數（x times a day）：顧名思義，一天可以用幾次。
- (iii) 損壞率（Breakable %）：代表每次使用時道具損壞的機率。藥瓶（Vial）固定損壞率 100%，也就是說只能用一次。

(3) 護身符（Amulet）和戒指（Ring）這兩種道具，充能、每日次數、損壞率三種配置都可能隨機出現。想要特定類型的話，在確認附魔的時候取消，重複操作直到抽到想要的類型為止。

(4) 賦能力量的法術強度是固定的，不會因為附在哪個道具上而改變。例如治療術（Heal）永遠是 8 點，不管附在徽章（Medallion）、法杖（Staff）還是戒指（Ring）上都一樣。這也表示，如果單純想要治療效果，選生命之息（Breath of Life）不會比選治療術（Heal）多任何好處。

(5) 賦能力量可以附魔成微弱、中等、強效三個等級，影響如下：

- (i) 充能型道具：微弱 4 次充能，中等 9 次，強效 14 次。
- (ii) 每日次數型：微弱每日 1 次，中等 2 次，強效 3 次。
- (iii) 損壞率型：微弱 17%，中等 12%，強效 7%。

(6) 武器與護甲最高可以附魔到 +10。武器每 +1 同時提升命中率與傷害；護甲每 +1 提升 1 點護甲值。

(7) 武器還可以附加特殊力量（Special Powers），本質上是待發動的法術，每次打中敵人時都有機率觸發。

(8) 用比較好的材質做的道具，附魔會有折扣。材質等級如下（以下數字是把一個 8 點強效賦能力量附魔到該材質的武器或護甲上要花多少錢，換算下來大約每高一級材質折扣 5%）：

| 花費 | 材質（原文） |
|---|---|
| 10548 | 一般（Normal） |
| 9993 | 精工（Well made） |
| 9438 | 銀製（Silver） |
| 8883 | 玉製（Jade） |
| 8328 | 水晶（Crystal） |
| 7772 | 黃金（Gold） |
| 7217 | 白金（Platinum） |
| 6662 | 寶石鑲嵌（Jewel encrusted） |

(9) 底下賦能力量的價目表用「微弱／中等／強效」三個數字表示，都是附魔到一般材質道具上的價格。

(10) 法術效果旁邊標 `*` 代表施放對象是使用者本人。例如「潛伏效果：6 點勝利之翼（Wings of Victory）*」，意思是觸發時會對使用者自己施放 6 點勝利之翼。
