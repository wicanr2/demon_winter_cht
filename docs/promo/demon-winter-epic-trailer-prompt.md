## 成片不可省略的四項硬閘門

| 項目 | 成片最低要求 | 驗收方式 |
|---|---|---|
| Modern 新片頭 | 使用 [`demon-winter-modern-title-v1.png`](../design/img/demon-winter-modern-title-v1.png)；開場先以局部冰霜揭幕，片尾再完整呈現。不得退回舊 EGA 標題當唯一片頭 | 逐幀確認中文字為「冬之魔」、英文為 `DEMON'S WINTER`，沒有裁字或生成錯字 |
| 實際遊玩畫面 | 世界行走、地城／事件、戰鬥、城鎮或航海至少涵蓋三類；主體必須是目前 HEAD 的實機錄影，不得以概念圖或生成動畫冒充 | 成片素材表記錄場景、種子、按鍵序列與來源片段 |
| `F8` 三主題切換 | 必須在**同一局、同一座標、同一狀態**實際按 `F8`，完整出現 EGA → CGA → Modern Icon → EGA；禁止用四張靜圖假裝切換 | 保留未剪輯的連續錄影母帶，核對金幣、糧食、時間、隊伍與座標不變 |
| 配樂與音效 | 使用已核准的 remake／宣傳片新編配樂，並保留可辨識的 PC speaker 音效、風聲與決戰前的動態抽空 | 片尾標示「宣傳片專用編曲；原版遊戲無背景音樂」，檢查整合響度與真峰值 |

缺少其中任一項，均不得把影片標為第二支正式宣傳片。

## 一句話定位

**一支像從冰封檔案中甦醒的 1988 電腦史詩：先讓觀眾感受當年有限硬體承載巨大
世界的不可思議，再以繁體中文 remake 重啟旅程，最後把選擇壓縮成與惡魔
澤瑞斯正面交鋒的一刻。**

片名不是一般的「復古遊戲功能介紹」，而是：

> **《冬之魔》——被 1988 年硬體封印，今日重新甦醒的華文史詩。**

## 與既有宣傳片不同的五項鐵則

1. 不再使用整片「黑底雙框＋置中標題＋淡入淡出」。
2. 敘事採「歷史考古 → 世界甦醒 → 決戰」三幕，而非逐項功能清單。
3. 實機錄影是主體；字卡只在轉折處出現，每張構圖都不同。
4. 色彩從 EGA 冰藍、凍土赭金、惡魔暗紅萃取，不沿用紫金奇幻模板。
5. 聲音有明確弧線：機械低鳴與 PC speaker → 鼓點加速 → 決戰前驟停 →
   銅管、戰鼓與遊戲音效同時落下。

## 片長與敘事節拍

目標片長 **72 秒、16:9、1280×720、25 fps**。

| 時間 | 幕 | 情緒與內容 |
|---:|---|---|
| 0–8 秒 | 冰封檔案 | 黑暗中浮出 1988、磁碟讀取感與 Modern 新片頭局部，不急著揭露全貌 |
| 8–22 秒 | 當年的巨大世界 | 世界地圖、五人隊伍、城鎮、地城、航海；用規模感而非功能清單 |
| 22–42 秒 | 經典重現 | 繁中介面、倚天 16×15、EGA／CGA／Modern Icon 以同狀態硬切換 |
| 42–57 秒 | 戰火逼近 | 海戰、怪物、法術、隊伍受創；剪接逐步縮短 |
| 57–66 秒 | 決斷 | 音樂短暫抽空，澤瑞斯台詞與魔王戰；攻擊落下時恢復全編制 |
| 66–72 秒 | 餘韻與召喚 | 片名、繁體中文 remake、GitHub；以冰霜呼吸聲與低銅管收束 |

## 導演總提示詞

以下可交給影片生成模型或作為人工剪輯的總導演規格。模型生成時仍須拆成下一節的
逐鏡提示詞，不能要求單一模型一次生成整支影片。

```text
製作一支 72 秒、16:9 的黑暗史詩電腦角色扮演遊戲宣傳片，主角是 1988 年的
Demon's Winter《冬之魔》繁體中文 remake。這不是懷舊搞笑片，也不是通用紫金色
奇幻手遊廣告；它像一份埋藏三十八年的冰封數位史詩重新啟封。

第一幕從黑暗、磁碟機低鳴與 Modern 新片頭的冰霜局部開始，再切入極少量 EGA
像素。新片頭必須直接使用專案核准的 `demon-winter-modern-title-v1.png`，
不可由影片模型重新拼寫標題。用克制的微距鏡頭、畫面掃描與逐層顯影，傳達在
1988 年極有限記憶體與顯示能力下，開發者仍做出世界探索、
五人隊伍、種族與職業、城鎮經濟、地城、航海、戰術戰鬥與龐大文字冒險的規模。
字幕只說「1988」「一個世界，裝進有限的記憶體」，不要捏造容量或開發人數。

第二幕讓遊戲世界甦醒。以真實 gameplay 為核心，鏡頭從 EGA 世界地圖、隊伍行走、
城鎮、地城與海上探索快速推進；使用同一遊戲狀態的硬切，展示 EGA、CGA 與
Modern Icon 三種主題，以及倚天 16×15 粗體繁體中文。保留原色，不把遊戲畫面
模糊化或假裝成預渲染動畫。畫面構圖交替使用滿版實機、地圖局部放大、左右對照、
縱向三聯畫與短暫無字畫面。

第三幕轉為決戰。海戰鼓聲過後，剪接逐漸縮短；怪物、法術範圍、受傷隊伍與
惡魔神殿交錯。魔王澤瑞斯出現前讓音樂突然抽空，只留下低頻心跳、風聲與一句：
「殺了我，毀滅不會就此結束。」鏡頭保持在真實戰鬥畫面，短暫停頓後由玩家確認
攻擊；輸入決斷的瞬間，以戰鼓、低銅管、合唱與原作 PC speaker 音效同時重擊。
不是無敵英雄爽片，而是明知代價仍選擇前進。

聲音採三段弧線：開場為磁碟機機械聲、寒風與稀疏 PC speaker；中段加入由
《冬之魔》陣亡旋律音型延伸的低弦與戰鼓；決戰加入低銅管、混聲合唱與巨大撞擊，
但保留動態範圍，不能從頭到尾都最大聲。此音樂必須標為宣傳片專用編曲，不能
宣稱是 1988 原版 BGM。片尾回到寒風、低音持續音與一次清楚的 PC speaker 音符。

視覺關鍵字：冰封檔案、EGA 冰藍、凍土赭金、惡魔暗紅、黑曜石、低霧、CRT 微光、
實機畫面、歷史重量、決斷、文明保存。避免：紫金色通用奇幻模板、手機遊戲 UI、
假 3D 重製畫面、任意新增角色、無目的漂移鏡頭、過量粒子、每鏡都慢速推近、
無法從遊戲重現的功能、把 Modern Icon 說成原版素材。
```

## 逐鏡生成提示詞

每個提示詞只負責一個 3–8 秒鏡頭。若使用影像轉影片，第一幀必須是專案內已核准
的實機截圖；不得重畫其中的 UI 文字或任意改變人物數量。
鏡頭 00 與 01 合計占用時間表的 0–8 秒，不額外拉長 72 秒總片長。

### 00 — Modern 新片頭揭幕，3 秒

```text
只使用已核准的 demon-winter-modern-title-v1.png，不重新生成圖像或文字。
從純黑開始，寒風捲起細雪，先揭露「冬之魔」冰鐵字樣與斷裂鎖鏈，再用一次極短
白色冰光帶出面對魔神的五名冒險者。鏡頭只做 100% 到 103% 的極慢推近，不能裁掉
中英文標題，不能增加副標。第三秒以磁碟機啟動聲硬切下一鏡。
```

### 01 — 冰封磁碟，5 秒

```text
微距固定鏡頭，一張沒有品牌標誌的 1980 年代黑色軟碟置於結霜的深色桌面，
冷藍側光只照亮邊緣；霜紋非常緩慢地沿表面擴散，背景完全沉入黑暗。鏡頭不漂移，
最後一秒由一次磁碟機讀取聲切入純黑。聲音：低沉機械轉動、微弱寒風、沒有音樂。
```

### 02 — 1988 的規模，7 秒

```text
從真實 Demon's Winter DOS EGA 世界地圖截圖開始，不修改像素與 UI。畫面由局部
逐層顯露成完整 4:3 實機畫面，像資料從磁碟逐行載入；外圍是黑曜石色空間與極淡
CRT 掃描光。字幕依序出現：「1988」「一個世界，裝進有限的記憶體」。聲音：
磁碟讀取節奏轉成兩個低弦脈衝，最後以原作 PC speaker 單音銜接下一鏡。
```

### 03 — 世界甦醒，8 秒

```text
滿版真實 EGA gameplay，五人隊伍在世界地圖連續行走，地形與人物保持最近鄰
像素邊緣；人物採核准的透明地形疊圖並保留薄黑輪廓。鏡頭完全由 gameplay 自身
運動驅動，不做人工浮動縮放。聲音：步伐感低鼓、寒風、稀疏 PC speaker。
```

### 04 — 三種時代同一世界，6 秒

```text
同一座標、同一方向、同一遊戲狀態，畫面隨三次乾脆的 F8 切換依序呈現 EGA、
CGA、Modern Icon；每次切換都對準音樂節拍，不能用交叉溶解。最後停在 Modern
Icon 一秒，再切回 EGA。字幕只寫：「經典還原，也讓今日玩家選擇」。聲音：
三次不同音高的 PC speaker 點音加短促空氣切換聲。
```

### 05 — 華文重現，6 秒

```text
左右分割構圖：左側是地城敘事與倚天 16×15 粗體繁體中文，右側是隊伍狀態與
整齊的現代命令欄；兩邊都是真實 gameplay，不生成新文字。中央分割線像冰裂紋，
但不遮擋任何字。鏡頭固定，讓觀眾有時間閱讀。聲音：低弦持續音、翻頁點音。
```

### 06 — 海與地下，7 秒

```text
三聯畫節奏蒙太奇：海上航行、陰暗地城、戰術戰場，各段 1.5 至 2 秒，以地圖格
線或門框作匹配剪接；保留真實 UI，不加金框。色調從海水冰藍轉為地城黑色，再到
戰鬥暗紅。聲音：浪聲、石門低響、武器金屬撞擊依序接棒，戰鼓開始加速。
```

### 07 — 魔王之前，5 秒

```text
真實惡魔神殿或高風險遭遇 gameplay，畫面先有怪物與法術，再突然切黑半秒，
回來時只見澤瑞斯戰場與中文台詞。不要生成配音；字幕使用遊戲內既有文字：
「殺了我，毀滅不會就此結束。」音樂在切黑時完全停止，只剩低頻心跳與風。
```

### 08 — 決斷，6 秒

```text
越肩感不是 3D 攝影，而是以真實戰術棋盤構圖強調玩家單位、攻擊目標與澤瑞斯。
游標移到攻擊命令，停頓半秒後確認；命中瞬間快速放大戰場局部 108%，立刻回正，
配合低銅管、戰鼓、混聲合唱與金屬重擊。畫面不能捏造傷害數字或未實作動畫。
情緒是明知代價仍作出選擇，不是輕鬆勝利。
```

### 09 — 今日重現，6 秒

```text
先以三個窄幅視窗各閃過 EGA、CGA、Modern Icon 的真實 gameplay，接著硬切到
已核准的 demon-winter-modern-title-v1.png 完整畫面。不得用影片模型重新生成
或拼寫「冬之魔／DEMON'S WINTER」。在下方安全區疊上可編輯文字副標：
「1988 史詩角色扮演經典・繁體中文 remake」，再顯示 GitHub 專案名稱；不得遮住
五人隊伍與標題。聲音：合唱結束後只留寒風、低銅管尾音與一個清晰 PC speaker
音符。
```

## 宣傳片專用配樂提示詞

```text
創作一段 72 秒的黑暗奇幻史詩遊戲預告配樂，專屬於 1988 電腦角色扮演遊戲
《Demon's Winter／冬之魔》的經典重現。音樂不是現代英雄爽片，也不是持續轟鳴
的通用 trailer cue；它要有歷史重量、寒冷、探索未知與面對魔王前的決斷。

0–8 秒：無旋律，只有寒風、磁碟機般的機械脈衝、極低音提琴泛音。
8–22 秒：以稀疏低弦呈現原作 PC speaker 陣亡旋律的音型輪廓，速度 72 BPM，
音域低、留大量空間。
22–42 秒：加入框鼓、低音鼓與大提琴節奏型，逐漸建立旅程感；不要太早加入合唱。
42–57 秒：轉為 96 BPM，戰鼓、低銅管、弦樂 ostinato 逐層加入，每四小節增加
張力，但保留遊戲 PC speaker 點音可穿透的中高頻空間。
57–60 秒：全編制驟停，只留心跳、寒風與極低音持續音。
60–66 秒：決斷重拍，低銅管主題、戰鼓、混聲合唱同時進入；第 64 秒設計一次
最大的命中重音。
66–72 秒：迅速抽掉打擊樂，銅管與合唱留下未完全解決的和聲，最後由一個乾燥的
PC speaker 音符收尾。

音色：低弦、低銅管、戰鼓、框鼓、混聲合唱、金屬撞擊、寒風、機械脈衝。
動態：從 -24 LUFS 左右的稀疏開場推進到決戰，但整體整合響度約 -14 LUFS，
真峰值不高於 -1 dBTP。不要電吉他、不要現代 EDM drop、不要過亮的好萊塢大調
英雄旋律、不要全程合唱、不要使用任何其他遊戲或電影的可辨識旋律。
標示方式：「宣傳片專用編曲；原版遊戲無背景音樂」。
```

## 拍攝與真實性閘門

- MobyGames 的 DOS 截圖只作跨畫面研究參考；成片使用本專案可重現的 DOS／remake
  實機畫面，不直接搬用網站圖片。
- 「1988」有原版發行資料支持；「龐大」以實際系統、地圖、文字與戰鬥內容呈現，
  不捏造磁碟容量、團隊人數或銷量。
- Xeres 台詞取自已翻譯的 `DATA4.TXT`；若該事件尚無可重現拍攝路徑，改用已完成
  的 Xeres 固定遭遇畫面與獨立字幕卡，不偽裝成事件已完整演出。
- 生成式過場不得冒充 gameplay；若使用，畫面角落或影片說明標為「概念過場」。
- Modern 新片頭只准使用專案內核准 PNG 作影像來源；可以做遮罩揭幕、冰霜與輕微
  鏡頭運動，但不得交給模型重畫標題文字或角色。
- `F8` 段落必須來自一次不中斷的實機錄影；剪輯可縮短停留時間，但不能重新排列
  主題順序，也不能以靜態 P4 審查圖代替按鍵切換。
- 配樂必須具有可公開使用的授權或由專案持有人自行生成／委製；原作沒有 BGM，
  片尾說明不得省略。
