## 一、劇情簡介〔p.1–2〕

> 時間：寶石月的第七天（The seventh day in the month of the Ruby）
> 地點：伊得琳村（Ildryn）

如血絲般的殘霞佈滿天空，夕陽的光暈逐漸消褪在遙遠的山頭，大地一片死寂。天空顏色由原本的橙紅，
不可思議地變成了紫藍，所有的村民都感受到莫名的危機。村民們圍聚在通往村莊的南方入口處，
深怕有什麼可怕的惡魔闖入這原本平靜的伊得琳村。他們手上拿著刀劍、斧頭、弓箭等各種武器，
卻仍忍不住地發起抖來。

就在日頭沈入山頭的那一剎那，遠處突然傳來陣陣的蹄聲，這蹄聲由遠而近，越來越大聲，
全體村民握緊了手中的武器，摒息以待⋯

面目猙獰，長著尖銳獠牙的怪物終於出現了，牠們揮動著血紅色的旗幟，手握銳利的巨斧，
衝向伊得琳村，牠們的數目比村民多了一倍。這支由 Kobolds 組成的隊伍是由惡鬼（Goblins）所領，
這些惡鬼以「艾克里斯」（Xeres）的名號召集這些 Kobolds，牠們的口號是
「榮耀歸於艾克里斯」「稱頌歸於主人艾克里斯」。

一場慘烈的戰爭終於在黃昏時展開，村民雖然奮力抵抗，終究敵不過可怕的 Kobolds，
伊得琳村到處都染滿了鮮血，不一會伊得琳村就成了一處廢墟，哀號哭泣的聲音在淒冷的冬夜裡聽來更覺得可怕，
這支怪物兵圍殺了村裡所有的成年人，只留下柔弱的小孩⋯

翌日，逃過一劫的孩童望著自己的家園在一夜之間變成廢墟，耳中響起昨夜掙扎的父兄彌留的一句話
「⋯為我復仇⋯為我復仇⋯」

> 包裝背面另有補充：本作是《春之石》（*Shard of Spring*）的續作，
> 故事發生在春之石時代的 5000 年後，最終要與大惡魔 **Malifon** 決戰。

## 二、硬體配備〔p.2〕

1. 主記憶體至少 384K 的 IBM PC／XT／AT 或與其 100% 相容之機型
2. 單色顯示卡（MGA）或彩色顯示卡（CGA／EGA）
3. 一台磁碟機
4. DOS 2.1 以上之版本
5. 搖桿（非必需）

## 三、載入硬碟〔p.2–3〕

1. 依一般啟動硬式磁碟機之步驟啟動電腦
2. 待 `C>` 出現後，鍵入 `MD DEMONS`＋ENTER，再鍵入 `MD DEMONS\DEM-DATA`＋ENTER
3. 將 GAME DISK 置於 A 磁碟機，鍵入 `COPY A:*.* C:\DEMONS`＋ENTER
4. 待 `C>` 再度出現，鍵入 `COPY A:\DEM-DATA\*.* C:\DEMONS\DEM-DATA`＋ENTER
5. 取出 GAME DISK，置入 DATA DISK，按 `F3`＋ENTER（此磁片檔案較多，需稍待）
6. 取出 DATA DISK，置入 DATA DISK B，按 `F3`＋ENTER，出現 `C>` 即完成

> ⚠ 手冊寫的資料目錄是 `DEM-DATA`（連字號），但本專案手上的原版檔案樹是
> `DEM_DATA`（底線）。以實際檔案為準。

## 四、啟動遊戲〔p.3–5〕

### A. 軟式磁碟機啟動

1. 以 DOS 2.1 以上版本開機
2. 待 `A>` 出現，將 GAME DISK 置於 A 磁碟機
3. **單色顯示卡（MGA）使用者鍵入 `PLAY`；彩色顯示卡（CGA／EGA）使用者鍵入 `DEMONS`**，
   按 ENTER 後出現標題畫面及音樂
4. 出現 `Insert DATA DISK / CONTINUE` 時，換入 DATA DISK 並按 ENTER
5. 隨後出現主選單

> **這是「原版有兩支執行檔」的一手證據。** 本專案手上的 dump 只有 `DEMON.EXE`＋`DEMON.INT`，
> 既沒有 `PLAY`（MGA 單色版），也沒有 `DEMONS`。MGA 版目前無從逆向。

### B. 硬式磁碟機啟動

待 `C>` 出現後鍵入 `CD\DEMONS`＋ENTER，其餘同上（硬碟版會自動尋找檔案，可省略換片步驟）。

### 主選單〔p.5〕

標題畫面字樣：`DEMON'S WINTER / Version 1.0 / Designed by Craig Roth and David Stark /
Copyright 1989 by Strategic Simulations, Inc.`

| 選項 | 說明 |
|---|---|
| **Go Adventuring** | 進行遊戲 |
| **Character Utilities** | 創造人物 |
| **Alternate Character Set** | 取用人物——若你曾玩過《春之石》，可將其中的人物傳入本遊戲 |

進入遊戲前須創造五名人物。在主選單按 `G` 進入探險前，**必須通過一道防拷密碼**，
答案可在附錄的表格中找到。

書中示範的題目是：`What is the intellect point cost of Monster Lore for a Paladin?`
答案 `4`。

> 這題的答案就在附錄 A：辨妖術（Monster Lore）那一列、職業 2（武士 Paladin）那一格 = 4。
> **防拷題庫直接取自附錄 A 的 310 個格子。**

## 五、控制方法〔p.6〕

選單指令一律**鍵入該選項的第一個英文字母**；帶編號的清單則按對應數字。

```
(a) Donations（奉獻）  Pray（祈求）  Converst（改變信仰）  Quit（退出）
    → 要奉獻金幣給神廟就按 D，想退出按 Q
(b) 1) Take（拿取）  2) Drop（丟棄）  3) Use（使用）
    → 要拿取物品按 1，使用物品按 3
```

⚠ `Converst` 是 `Convert` 的錯字。

## 六、進入遊戲前的準備〔p.7–17〕

### 1. 創造人物〔p.7〕

須創造五名人物。流程為：選種族 → 擲屬性 → 選職業 → 選技能。

### 種族〔p.7–8〕

五個種族的屬性上限見[附錄 B](./02-appendix.md#附錄-b各人種屬性的最大值)。
各種族另附一項天生能力：

| 種族 | 天生能力（手冊記載）|
|---|---|
| 人類（Human）| 優缺點：無 |
| 精靈（Elf）| 感知魔法 |
| 矮人（Dwarf）| 夜視（Darkness Vision）|
| 黑暗精靈（Dark Elf）| ⚠ 手冊記「具醫療之能力」，英文原版是 **Power Leech（汲取法力）**|
| 洞穴巨人（Troll）| ⚠ 手冊記「可復活」，英文原版是 **Regeneration（再生）**|

> ⚠ **手冊的巨人屬性修正欄有誤**：手冊記「力量 −1、智力 −3、耐力 +2」且無速度修正，
> 但由附錄 B 的上限表推導、且經 DOSBox 實測畫面確認，實際是「速度 −1、力量 0」。
> 詳見 `docs/spec/05-character.md`。
>
> 另外手冊說人類「無優缺點」，但程式碼給人類每項屬性 **+2**（五項共 +10），手冊沒寫。

### 2. 屬性〔p.9–10〕

| 屬性 | 作用 |
|---|---|
| speed（速度）| 決定移動速度、戰鬥所需時間長短，以及能否取得攻擊先機、主動攻擊 |
| strength（力量）| 越高傷害越大；有武器時所需的力量點數可以較低 |
| Intellect（智慧）| 決定可使用的武器數量與技巧複雜度，以及可選擇的法術項目 |
| Endurance（耐力）| 能忍受的傷害程度 |
| skill（技巧）| 使用武器的能力 |
| level（等級）| 一開始均為 1，隨經驗提升 |
| Hit points（生命點數）| 為 0 即死亡；可藉睡覺與魔法回復 |
| spell points（法力）| 可藉睡眠回復 |
| Experience（經驗點數）| 殺死怪物取得 |

**擲點與三次重擲機制：**

> 前五種屬性的點數由電腦依不同種族隨機決定。選擇種族後，畫面左方顯示五項屬性的點數，
> 右邊方框內的數字表示各項屬性在該種族中的**平均點數**。
>
> 你有**三次機會**可以影響這些點數。將電腦給的點數與方框內的平均點數相比較，
> 若覺得某項屬性點數**低於 6**，可按該項屬性前的號碼再按 ENTER，電腦會重給一個點數。
> **三次機會用完後，該項屬性點數就無法再改變。**

> 這條規則目前**尚未在程式碼中定位**。`docs/spec/05-character.md` 的建角段落只涵蓋
> 擲點公式與種族修正，重擲機制是待補項。

### 3. 職業〔p.10–13〕

共 10 種。手冊的職業代號（見附錄 A 表頭）為
`1` 流浪漢、`2` 武士、`3` 野蠻人、`4` 和尚、`5` 牧師、`6` 賊、`7` 巫師、`8` 魔法師、`9` 幻想者、`10` 學究。

| 職業 | 手冊說明 |
|---|---|
| **Ranger 流浪漢** | 具野外求生本能的戰士，熟悉全部武器技巧並能辨識怪獸加以捕殺。大部分法術完全不懂，但可學習行風術（Wind Runes）|
| **Paladin 武士** | 佩戴閃亮盾牌的忠誠劍客，幾乎全是僧侶。因信仰緣故容易被說服，交易時尤其如此；擁有讀心術，交易時能看穿商人是否撒謊。視魔法為邪惡，除了攝魂術（Spirit Runes）這類治病或復活的法術外不使用魔法 |
| **Barbarian 野蠻人** | 具威力的戰士，戰鬥時非常瘋、有失去理智的傾向。慣用斧及矛鎚，偶而較聰明的會學刀劍。只會一種法術——施冰術（Ice Runes）。很少事奉神明，但有少許會敬拜自創的神 |
| **Monk 和尚** | 善於徒手作戰並熟悉古代知識，有強烈宗教信仰，很多都學有「功夫」|
| **Cleric 牧師** | 敬拜多神的教士，絕不使用鋒利武器（偶而用匕首），防身武器多為矛鎚或空手道。與武士一樣擁有讀心術 |
| **Thief 賊** | 暗中活動、身手敏捷。對戰鬥及陷阱均非常在行，對敵人的甲冑能很有技巧地加以反擊 |
| **Wizard 巫師** | 精通魔法，尤其專長各類古代魔法（Rune Magic），擅長施展火團、強風、冰雪及魂魄之召喚術。可辨別各類藥物及學習使用武器，但只能使用最輕型的武器。地位比魔法師更高，且可用較短時間學習狩獵 |
| **Sorcerer 魔法師** | 黑暗勢力中最擅長召喚術（Summoning）及幻影術（Illusion）的人物。比巫師更兇猛、更擅長使用武器。⚠ 手冊寫「是最容易進入**領地**（Possession）的人物」——`Possession` 在此應譯「附身／附魂術」，非「領地」|
| **Visionary 幻想者** | 新的角色，可學習較不尋常的技巧，如觀地術（View Land）、觀心術（View Mind）、觀房術（View Room）及觀物術（View Item），更可穿戴極重的盔甲，並可學習魔法師所有的法術 |
| **Scholar 學究** | 知識領域中的奇才，尤其熟知藥物、物品及怪物。精於戰術謀略，對怪物的下一步行動瞭若指掌。稍經訓練便可學習使用一些較小的武器或空手道 |

### 4. 技能〔p.13–17〕

每種技能賦予人物某種能力（例如沒有劍術就無法使用刀劍），每種技能都有其施展能力點數。
技能表上方會顯示總共最多可使用多少點，只要所挑技能的點數總和不超過限制即可；
可選的技能種類依職業而不同。

**建角時只能挑選兩種技能**；進入遊戲後可在學院（College）中學習新技能。
挑選後若仍有未使用的技能點數，可以保留。

各技能的學費見[附錄 A](./02-appendix.md#附錄-a技能學費表skill-point-costs-by-class)。

## 七、進入遊戲〔p.18–36〕

### A. 伊姆洛斯王國探險

#### 1. 地形〔p.18–20〕——七大地形

| 地形 | 說明 |
|---|---|
| Plains 平原 | 最普遍的伊姆洛斯地形。可發現各種人物、探險者及賊，也有野狗、毒蛇甚至一些龍 |
| Forest 森林 | 棲息熊、野狼、人類。不死怪物與昆蟲、毒蛇及神秘潛行怪物一起出現；有些棲息者能施行幻術驅使林中怪物作戰 |
| Swamp 沼澤 | 相當污穢。有些類人族（如 Kobolds）不進入沼澤也不傷害探險者；昆蟲及毒蛇非常多，不死怪物很少。要注意鬼墳族（Shambling Mounds）與鬼火（Will o'the Wisp），後者法術極強 |
| Hills 山丘 | 有許多巨人及可怕的熊。**穿過本地形所花費的時間可能是一般地形的兩倍**。龍也棲息在丘中，探險者經常在此屠龍並尋找寶藏 |
| Tundra 凍土苔原地帶 | 北極熊、寒帶野狼出沒；曾發現名為 Yeti 的雪人。不死怪物、巨雪人（Snow giants）、冰龍（⚠ 原文誤印 `ic dragons`）、冰魔（ice demon）都可能出現 |
| Kudzu 樹叢 | 地面佈滿樹藤且分佈迅速廣大。類人族、探隊者、昆蟲及龍都可在此發現 |
| Desert 沙漠 | 極單調，除了些賊之外其他人類不願前來。大部分苦修的僧侶（dervishes）及蜥蜴人（salamanders）居住於此；僧人可施行火熱的旋風，蜥蜴人可以毒蛇的樣子出現並施展火球。龍及毒蛇偶而也可發現 |

#### 光線與時間〔p.21〕

> **在伊姆洛斯中，一天有 26 小時，而一個月則有 34 天。**

> ⚠ **「26 小時」與程式碼對不上。** 一個月 34 天精確吻合（日 wrap 35），
> 但小時的 wrap 常數是 `0x26` = **38**。`docs/spec/06-time.md` 的推測是：
> 英文手冊作者把十六進位常數 `26h` 讀成了十進位 26。
> **中文版是英文版的翻譯，繼承同一個數字，因此不構成獨立佐證。**

探險中隨著時間消逝，可看到的範圍會越來越小，表示夜幕漸低垂、能見度變差，
此時最好立即紮營。按 `P` 鍵會有其他相關訊息可選。

#### 狩獵〔p.21〕

在野外或在船上，每日一次出去找尋食物，能否找到須靠運氣。

#### 2. 神祇〔p.21–24〕

伊姆洛斯中有兩股不同的神力。一般的百姓事奉 **Priest gods**，
野蠻人（Barbarian）則事奉 **Shaman gods**。敬拜者可呼求所事奉的神明作為急難救助。

**Priest gods**

| 神名 | 神職與說明 |
|---|---|
| 巴姆爾（Balmur）| 時間之神。以一隻有著星光眼睛的大金鷹為標記，其法力可使人衰老，信徒眾多 |
| 維馬（Vemarkn）| 魔法女神。管理古代魔法（⚠ 原文印 `Ruinc`，應為 `Runic`）及吟詠（Chant）|
| 馬多拉斯（Maldorath）| 死亡之神。只在惡夢中出現，供奉的神廟很少而且隱密 |
| 伊洛（Illo）| 生命之神。許多城市的守護神，可賜人性命，尤其紮營後向祂祈求常可使人復活 |
| 卡蜜爾（Camear）| 和平之神。不論野外或城市都有事奉祂的神殿，可使敬拜者遠離戰鬥、回歸寧靜 |

**Shaman gods**

| 神名 | 神職與說明 |
|---|---|
| 歐米西（Omizeh）| 生命之神，與伊洛相似。標記是一個年輕女子、天鵝或一隻大的白鳥 |
| 賈牟（Gamur）| 死亡之神。殘暴的凶神，嗜食腐肉，敬拜者都住在遠離城鎮的野外 |
| 亞西司（Acisc）| 戰鬥之神。標誌是一頭兇猛的獅子或老虎，是 Shaman gods 中最常見的神祇之一，尤其在城鎮教授戰鬥技巧的地方。可提供戰鬥的持續力 |
| 波羅米憂（Volobews）| 美藝之神。風遨遊，像夾著翅膀的男神，可提供如風般的速度 |
| 塞尼（Theryri）| 魔法之神，和維馬相似，具極強的法力。如今只有**諾斯城（Ynoth）**——位於樹叢中的古城——還有向祂敬拜的人。標誌是有著紫藍色眼睛的黑烏鴉 |

**Deity Calls 祈求神助**〔p.23〕

- 有些神只有當祈求者處在戰鬥或已紮營時才會應答
- **第一次祈求只有 20% 的機會被接受**
- 一次成功的祈求且該神已賞賜能力後，**以後的祈求成功率會遞減 5%**
- 時常祈求可能會讓該神厭煩甚至置之不理
- 有時必須在該神的神殿中祈求方為有效

**Turn undead 驅逐不死怪物**〔p.24〕

Priest 及 Shaman 之眾神都有驅走不死怪物的法力，對象包括僵屍（Zombies）、骷髏（Skeletons）、
鬼魂（Ghosts）、幽靈（Spectres）及生靈（⚠ 原文印 `Waiths`，應為 `Wraiths`）。
能否驅走視不死怪物與眾神的法力孰強而定。

#### 3. 神廟與教會〔p.24〕

伊姆洛斯廣大的土地中有許多神廟與教會供奉不同的神祇，而**教會（Church）一般只在城市中才有**。
祈求多次後想恢復成功率，必須回到該神明的神殿或教會中祈求（需付費）。

若祈求者本身並不事奉該神而想成為信徒，這些教會或神殿便是最佳地方。
**奉獻（捐助）的每一金幣都會獲得一個經驗點數作為回報。**

#### 學院 COLLEGES〔p.25〕

探險中一定可發現一些學院，城市中有時不只一所。**學院是教授技巧的最佳地方（要收費），
而每一所學院只傳授一項技巧**，收費標準隨技巧難易而不同——例如流浪漢學狩獵相當容易，
魔法師就相當費力。

像劍術及破解陷阱這種一般技巧有許多學院都有傳授，但較難或較冷門的項目可能只有一、二所學院有，
**每一種古代魔法及吟詠都只有一所學院傳授**。

#### 4. 城鎮〔p.25–28〕

剛開始探險時你正在一處城鎮附近，可進去購買武器。每個城鎮上都有不一樣的物品可買，
有些城鎮有奇特的舶來品；東西越奇怪，販賣的遠地商人也更奇特。

有些城鎮內全城的百姓只事奉特定的一位神明，這時選單會顯示 `C` `Church of XXX`。

進入城鎮後的選單（鍵入第一個字母）：

| 指令 | 項目 |
|---|---|
| `G` 或 `M` | Go to marketplace（進入商店）|
| `H` | Healers（治療）|
| `R` | Rest in the Inn（在旅館內休息）|
| `C` | Church of XXX（該城守護神的神廟）|
| `P` | Pub（酒店）|
| `I` | Inspect character（檢視人員）|

**商店（Marketplace）指令**

| 指令 | 說明 |
|---|---|
| `B` | 回到上次所看到的物品清單 |
| `H` | 與商人討價還價以獲得較低的買價。太離譜的低價商人會認為你缺乏誠意，即使再提升買價也不賣。**如果隊員中有人具有說服（Persuasiveness）能力，即可成交** |
| `P` | 購買物品，電腦會詢問由哪一位隊員購買。**購買後必須離開商店紮營休息或離開該城市，才能將所購買的物品佩戴（equip）在身上** |
| `S` | 賣出探險所得的物品。**剛買的裝備物品無法出售** |
| `I` | 確認一件**定價在 75 塊金幣**的物品；有適當的知識（Lore）也能辨識出用途 |
| `#` | 鍵入 `1`–`5` 選定由誰交易，無須離開商店 |

**城鎮設施**

| 設施 | 說明 |
|---|---|
| Healers 療養所 | 受傷、生病、受綑綁甚至死亡者均可抬進接受治療。**收費決定於接受治療者的傷害程度**，大多不會太貴 |
| Inns 小旅館 | 提供過夜或休息。**恢復體力的程度是露宿在外的 2 倍**，可過上數夜，收費連同飲食在內 |
| Guilds 互助會 | 協助隊員提升等級，先決條件是具備足夠經驗點數。進入後電腦會顯示所有隊員晉升一級各需多少經驗點數。**互助會中的任何交易都是免費的** |
| Colleges 學院 | **一個城鎮內一般都會有三所學院**，鍵入 `1`–`5` 選定進入學習技能的隊員 |
| Tavern 酒店 | 可購買飲料或聽取閒談、傳說。**飲料每人一天只能買一份**，五個人可個別買五份供晚上紮營時飲用 |
| Docks 碼頭 | 可購買船隻，都在沿海城鎮中。各城鎮碼頭的船價不太一樣，破損的船隻也可在碼頭修護 |

#### 5. 紮營〔p.28–31〕

紮營時可治療輕微傷害、補充符咒點數、改變佩戴之裝備等。
**只要不在城鎮內隨時都可按 `C` 紮營休息，但戰鬥中無效。到了夜晚若隊員正在野外，則會自動紮營休息。**

鍵入 `1`–`5` 可檢視隊員狀況：先出現屬性（Attributes），按任一鍵查閱次頁，按 `ESC` 退回。
最後一頁顯示隨身物品，符號意義如下：

| 符號 | 意義 |
|---|---|
| `/` | 地牢內的物品（Dungeon Item）|
| `$` | 有價物品（包括金幣、寶石⋯）|
| `*` | 法術（Magic）|
| `?` | 未知物品（未經確認）|
| `→` | 已裝備 |

紮營指令：

| 鍵 | 指令 | 說明 |
|---|---|---|
| `C` | Cast 施行法術 | 紮營休息時施展法術，例如治病、解除束縛或甦醒（Resurrect）|
| `D` | Drop 丟棄物品 | 地牢撿到的物品丟掉後可再撿起，有些則很難再撿回；**已佩戴的物品（如甲冑）無法丟棄** |
| `E` | Equip 佩戴 | 列出隊員擁有的物品供選擇佩戴。**若該隊員的力量值少於該武器所需的最低點數，則無法佩戴或使用** |
| `H` | Hunt 狩獵 | 具狩獵技能的隊員可出去找食物，**一天只能狩獵一次**。找到後自動裝進食物清單 |
| `I` | Identify 辨認 | 具相關知識的隊員可辨識物品及用途，**一天也只能辨識物品一次** |
| `P` | Print 列印 | 有印表機時可列印人物。按 `P` 後選人物代號 `1`–`5`，或 `A` 列印所有隊員、`E` 列印其他隊員 |
| `R` | Reorder 改變戰鬥隊形 | 遭遇攻擊時可將最弱的隊員擺在中間（⚠ 原文印為 `Recorder`）|
| `S` | Sleep 睡覺 | 補充生命點數及符咒點數。天色尚早時電腦會告知無法睡覺。**睡覺可恢復 1 個生命點數及 5 個符咒點數（一天）** |
| `T` | Trade 交易 | 隊員間可相互交易物品，**但武器無法彼此交易** |
| `U` | Use | 使用物品或武器 |
| `V` | View land 觀陸術 | 按 `I` `J` `K` `M` 或方向鍵向四個方向觀察（⚠ 原文印「向西個方向」）。**一天只能使用一次**。按 `ESC` 回到紮營畫面 |
| `W` | Worship 事奉 | 紮營時所能事奉或祈求的神，只有魔法之神及生命之神（Magic and Life）|
| `X` | Exorcise 驅邪 | 須具有 Priest 或 Shaman 眾神中之祈求能力才可執行。成功的話，用以祈求的物品會自動丟棄。**一天只能使用一次** |
| `L` | Leave camp | 離開紮營處 |

#### 6. 商人（merchants）〔p.31〕

許多四處旅遊經商的商人會向探險者銷售一些無法在城鎮買到的奇特物品。
**像空的藥瓶（empty vials）或權杖（rods）只能向商人買而無法在商店中買到。**

**Level of Merchants 商人的等級**——商人等級高低並非隨機出現，而是**決定於你探險的程度**。
剛開始遭遇的商人大多貧窮且穿著破爛，隨著越向遠方探險，遇到的商人等級越高，售賣的貨品也更奇特。

**Caveat Emptor**——大部份商人都是老實的生意人，但有些是惡棍。例如你買一件有 22 個點數的
火焰棒（Flame Strike），可能花了錢卻什麼也得不到。**商人說謊成功一次後便會食髓知味，繼續撒謊。**
如果隊友中有人具有**觀心術（View Mind Skill）**，就可辨別商人所說的是真是假。

### B. 地底世界探險〔p.32–35〕

#### 光源〔p.32〕

地面上的光暗由日出日落決定，而地底世界全為漆黑，並且到處充滿陷阱、躲在暗處的怪獸。
獲得光亮的方式：

- **點亮火炬（torch）**——最簡單、最經濟
- **使用燈籠**——價格較貴，但較舒適
- 矮人（Dwarves）具夜視能力；有火炬時矮人能完全看清地底景物
- 隊員中有人具**夜視能力（Darkness Vision）**可克服這層障礙
- 使用魔法：**Magic of light、Fire Runes、Ice Runes** 也能照亮

> 這些地底世界全由具有夜視能力的矮人所挖掘。

#### 陷阱〔p.33–34〕

| 陷阱 | 效果 |
|---|---|
| 針牢（毒針）| 1–4 點傷害 ＋ 束縛 |
| 針坑（Punji pit）| 1–6 點傷害 ＋ 束縛 |
| 穿膛飛槍（Darts）| 1–3 點傷害 |
| 長矛（Spears）| 1–2 點傷害 |
| 陷阱地（水池）| 有 33% 的機會逃脫 |
| 強酸池 | 2 點傷害 |
| 警鈴（Alarm）| 招來怪物 |

**偵察與解除**：按 `L` 搜尋陷阱，**基礎成功率 25%；具偵測陷阱技能者 100%**。
觀房術（View Room）也能發現陷阱，但一天只能使用一次。

#### 物品指令〔p.35〕

| 鍵 | 指令 | 說明 |
|---|---|---|
| `I` | 檢視四周 | 自動掃瞄是否有物品存在。**光是四處走動並無法發覺物品**，故應經常按 `I` |
| `E` | 檢查物品 | 檢查隊員隨身攜帶或所面對之物品 |
| `T` | 拿取物品 | 從物品清單中拿取，有些物品無法帶走 |
| `D` | 丟棄物品 | 不限定丟棄地點，必要時尚可撿回 |
| `M` | 移動物品 | 移動物品以查看後面是否隱藏其他物品 |
| `U` | 使用物品 | 在物品清單中選擇 |

**Secret Door and Passages 秘密門與通道**——走道上有許多重要的秘密門被巧妙的魔法所隱藏，
看起來就和一般牆壁沒兩樣，發現了記得一定要進去。

**saving the game 儲存遊戲**——當畫面選單上出現 save 選項時，可按 `S` 儲存目前進度。

### C. 海上探險〔p.36–37〕

走到沿岸城市找到碼頭（dock）購買船隻後，可搭船進行海上探險，或到海中的島嶼。

| 項目 | 說明 |
|---|---|
| BUYING A SHIP 購買船隻 | 一艘船售價**大約 600 金幣**不等；一座沿岸城市可能有不只一處碼頭，**最多可擁有 10 艘船（包含船員）**|
| SHIP REPAIRS 船隻修護 | 破損時可回任一碼頭修護，價格依受損程度而不同。**若船隻已完全破壞而無法修護，你及船上人員只好隨它沈入大海** |
| Damage 損壞 | **一般船隻擁有大約 75 個生命點數**。按 `?` 可顯示剩餘生命點數；降到 0 時沈入海中，船上人員一無倖免 |
| Runing 逃跑 | 航行到地圖邊緣的**出口點（Exit dot）**時，可從海上戰鬥中離開而不需經由沿岸城市的碼頭上岸（⚠ 原文印 `Runing`，應為 `Running`）|
| Treasure 寶藏 | 海上探險所獲得的最大寶藏就是和海盜、海怪戰鬥所換來的經驗點數 |

**SEA COMBAT 海上戰鬥**——海上航行遭遇的危險比陸地少，但仍有海盜、海怪。
海上戰鬥與陸地很相似：越靠近海盜船命中率越大，但被命中也相對增加，全看誰能取得攻擊先機。
海怪經常挪到船邊發動攻擊，企圖將船隻撕個破爛。

## 八、魔法〔p.37–42〕

古代魔法經常為巫師所使用，一般人則需花費相當大的代價才能施展。共分**地、水、火、風、魂**五類。

> 對照後續章節標題，「水」對應冰魔法（Ice）、「地」對應 Metal Runes、「魂」對應 Spirit Runes。
> 各法術的最低符咒點數見[附錄 C](./02-appendix.md#附錄-c符咒點數的最低值)。

### A. 火魔法（Fire Runes）

| 法術 | 說明 |
|---|---|
| Column of Fire 火柱 | 發射火柱燒毀敵人。**加入的符號點數越多，火就越旺烈、功力越高。穿著甲冑並不能抵擋本法術** |
| Fire storm 火暴風 | 形成 **5×5 單位面積**的風暴，區域內生物都將受到傷害。**開始戰鬥時不能先使用本魔法** |
| Flame Shield 火罩 | 用火保護某人物不受敵人的傷害 |
| Flame Strike 火拳 | 可直接使敵人致死，非常具有威力，但是不易施展 |
| Magic torch 魔炬 | 加入越多符號點數，魔炬的亮度就越亮 |
| Melt 鑄熔術 | 與冰凍術（Freeze）相反，用以解除被冰凍術拘束的人 |

### B. 地魔法（Metal Runes）

## 十、提示〔p.44–45〕

1. 創造人物時，至少要創造一位職業為巫師（wizard）的人物，並且給他有 Spirit Rune 的能力，
   否則當有人受傷或死亡時便無法醫治。
2. 創造人物時，**速度點數最好能高於 5**，低於 5 的速度點數會拖垮整個探險隊前進的速度。
3. 每個人物都有選擇兩種技能的權利，但技能種類依不同種族而有不同，
   因此若有可能，最好隊上能有一人擁有使用武器的能力（weapon skill）。
4. 購買裝備時一定要先討價還價，免得吃虧上當。
5. 選購武器時需先量力而為，請參考附錄 E。
6. 購買武器或裝備後，記得一定要先紮營休息（Camp）並藉以將購買之物品佩戴在身上（equip）。
7. 在探險中要記下所有的線索並且經常儲存遊戲進度。

> 提示 3 說技能種類「依不同**種族**而有不同」——實際上依**職業**而定（見附錄 A 表頭同樣的錯誤）。
