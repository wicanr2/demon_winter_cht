# 68 — 地城陷阱的數值

`docs/re/66` §3 把 `0x19ed7` 那張 9 格表定位成地城陷阱，
但只有字串沒有數字。這一篇把擲點讀出來。

---

## 1. 毒針（確定）

```
19ad5  印 "Poison needle hits "
19ae5  call 15be:153a          ; 選一名角色，回傳索引
19af1  cx = Roll(4)            ; ← 傷害 1–4
19afd  si = 索引 × 0x104
19b09  al = 角色[+0xfd]        ; 目前 HP
19b10  ax = HP − cx
19b19  call 15be:145c(索引, 新HP)
19b21  回傳 0 → call 15be:000c ; 全隊死亡（＝動作 0x18）
```

**傷害是 `Roll(4)`，打隨機一名角色。** 這條完整讀過：
從擲點、減 HP、寫回、到全滅判定都在上面。

`15be:000c` ＝ `25be:000c` ＝ `docs/re/50` 的動作 `0x18`
（`A cold breeze` / `chills the air...` / `...all characters` / `have died.`）——
**兩張表在這裡接起來了**。

> 攻略 `part-3.md` §19 說「陷阱頂多是個麻煩，**除非運氣夠差被毒針扎中**」。
> 傷害只有 1–4，對 HP 20 以上的角色確實不痛 —— 攻略特別點名它，
> 合理的解釋是毒針會附帶中毒狀態（`15be:145c` 那支還沒讀）。**未證實。**

## 2. 其餘四種的擲點（位置已知，語意未全部確認）

| 陷阱 | 字串 | 擲點 |
|---|---|---|
| 坑 | `A Bungei pit!` / `Poison pit!` / `: safe` / `: falls` | `Roll(2)`（`0x19bb7`）→ 疑似 safe／falls 判定；`Roll(6)`（`0x19c0a`）→ 疑似掉下去的傷害 |
| 長矛／飛鏢 | `Spear trap!` / `Darts shoot from` / `holes in the wall` / `%smisses` | `Roll(5)`、`Roll(2)`、`Roll(3)`、`Roll(4)` 四處 |
| 池 | `A pool!` / `An acid pool!` / ` falls in.` / `swims out.` / `Drowns. %d damage` | `Roll(3)` ×2 |
| 警報 | `You set off an alarm!` | `Roll(5)` |

**只有毒針那條逐指令追過**，其餘是「擲點位置 + 相鄰字串」的對照。
`Roll(2)` 挨著 `: safe`／`: falls` 很像成敗判定，但**沒有實際追運算元**，
所以這一節寫成「疑似」而不是結論。

`Drowns. %d damage` 這個格式字串說明池子的傷害是算出來後印出來的 ——
那個 `%d` 的來源值得追，它是唯一會把傷害數字顯示給玩家看的陷阱。

---

## 3. 兩種進入路徑

`docs/re/66` §3 注意到三種陷阱各佔兩格（case 2-3、4-5、6-7），
兩格指向**同一段程式碼**。現在有了字串可以對照：

- `A Bungei pit!` 與 `Poison pit!` 是同一格裡的兩條字串
- `A pool!` 與 `An acid pool!` 同理

所以那兩格的差別不是「偵測／觸發」，而更可能是
**普通版與有害版**（一般坑／毒坑、一般池／酸池），
由進入時的參數決定印哪一句。`docs/re/66` §3 當時猜的「偵測到／踩到」**不成立**。
