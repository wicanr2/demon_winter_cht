# 87 — 出貨的 `PARTY.DAT` 不是新遊戲，真正的起點在世界地圖

`CONTEXT.md` §7 的 A4 定義是「新開檔 → 建角 → 走主線 → 破關」。
前四輪的試玩全部從原版出貨的 `PARTY.DAT` 開始 —— 我一直把它當成起始狀態。

**它不是。它是一份玩過的存檔。** 而真正的起點在**世界地圖**上，
不是地城裡。

---

## 1. 兩個一眼就該起疑的線索

早在 `docs/playtest/01` 的第一張戰鬥截圖裡就有：

- **Menhir 的血是 15/27。** 一支剛建好的隊伍不會帶傷。
- 隊伍在**地城**（圖 1）的 (9,32)，日 17、時 13、金幣 65。
  剛開場的隊伍不會在地城深處。

我當時把兩件事都當成「原版就是這樣出貨」，沒有追。
`docs/re/78` §2 明明記過**同一組檔案的另一半也是玩過的**
（出廠的 `1SS`／`2SS` 帶著 29 處遊玩痕跡）。
**同一份出貨資料裡有一個檔案是髒的，其他就都要懷疑。**

## 2. 建角程式裡有寫死的起始值

新遊戲的初始化在 `Character Utilities`（`0x14567` ＝ `206a:02c7`）裡，
`0x148c8`–`0x1497f` 一連串立即數：

| 位址 | 欄位 | 值 |
|---|---|---|
| `0x148cc` | `+0x9b` 糧食 | `0x14` ＝ **20** |
| `0x148d6` | `+0xa1` X | `0x1c` ＝ **28** |
| `0x148e0` | `+0xa2` Y | `0x32` ＝ **50** |
| `0x148ea` | `+0xa3` 地圖 | `0x22` ＝ **34** |
| `0x148f4` | `+0xa4` 朝向 | 1（東）|
| `0x148fe` | `+0xa7` 光源 | 1 |
| `0x14908` | `+0x9e` 日 | **8** |
| `0x14912` | `+0x9f` 時 | **5** |
| `0x1491c` | `+0xa0` 步數計數 | 1 |
| `0x14933` | `+0x9c` 遭遇倒數 | `rand(5) + 0xe` ＝ 14–18 |
| `0x14942` | `+0x0a` 金幣 | `0x4b` ＝ **75**（高位字寫 0）|
| `0x1494c` | `+0xaf` 商隊基準 | 1 |
| `0x14956`–`0x1497a` | 船隻第 9 格 | (13,51) 圖 1，**船體 67** |
| `0x14984` 迴圈 | `+0x00`–`+0x08` 陣型 | 全部 `0xff`（空）|

月（`+0x9d`）不寫，留 0 ＝ 紅玉月。

### 與出貨存檔逐欄比對

| 欄位 | 出貨 `PARTY.DAT` | 新遊戲 |
|---|---|---|
| 糧食 | 8 | **20** |
| 日 | 17 | **8** |
| 時 | 13 | **5** |
| X, Y | (9, 32) | **(28, 50)** |
| **地圖** | **1（地城）** | **34（世界地圖）** |
| 朝向 | 2 | 1 |
| 金幣 | 65 | **75** |
| 步數計數 | 1 | 1 ✓ |
| 光源 | 1 | 1 ✓ |
| 商隊基準 | 1 | 1 ✓ |

**九個欄位不同**，其中最關鍵的是地圖：`1` 是地城、`34` 是世界地圖。
**那一個 byte 就是「從中段開始」與「從頭開始」的差別。**

> 這條寫成了測試（`internal/game/newgame_test.go`）。斷言的不是
> 「我的常數對」，是**「這兩份狀態不一樣」** —— 也就是為什麼
> `-newgame` 這個旗標必須存在。如果哪天有人把它「簡化」掉，測試會炸。

## 3. 起始那艘船的船體是 67，不是滿值

`0x14971` 寫的是 `0x43` ＝ 67，而滿值是 75（`ShipMaxHull`）。
**一開始就有一艘半舊的船。**

移植時不要「順手補滿」—— 那會改變玩家第一次要不要花錢修船的決定，
而修船價是碼頭經濟的一部分（`docs/re/28`）。

## 4. 引擎接上之後：`-newgame`

`internal/game/newgame.go` + `cmd/demonwinter` 的 `-newgame`。

**順帶炸出一個藏了很久的 bug**：引擎載哪張地圖，看的是 `-map` 旗標，
**完全不看存檔的 `+0xa3`**。`-map` 的預設值是 `MAP1.MAP`，
而出貨存檔剛好是圖 1 —— **所以這個 bug 一直被巧合掩蓋著**。

接上 `-newgame` 才炸出來：座標套用了（(28,50)）、地圖還是圖 1，
隊伍站在**另一張圖的同一組座標**上，走兩步就撞牆。
畫面上完全看不出是哪一張圖。

修法：`-map` 預設改成空字串 ＝「用存檔裡的地圖編號」，
而且地圖要在存檔（含 `-newgame` 的覆寫）決定之後才載。

## 5. 真正的開場長什麼樣

`docs/playtest/06` 有截圖。**5 時 8 日紅玉月，站在海邊的草原上，面向東。**

從 (28,50) 走得到的地點（`dwroute -reachable-exits` 與逐點測距）：

| 目標 | 步數 |
|---|---|
| **城鎮 (31,45)** ＝ 海濱鎮 | **8** |
| 學院 (18,48) | 12 |
| 城鎮 (46,45)／出口 (45,50) → 圖 2 | 23 |
| 學院 (49,40) | 31 |
| 出口 (55,18) → 圖 1（地城）| 59 |
| 城鎮 (45,34) | 61 |
| 城鎮 (37,23)／神殿 (33,33) | 72 |
| 學院 (46,7) | 93 |
| 神殿 (9,25) | 102 |

**一座城鎮在八步之內。** 這才是 1988 年 CRPG 該有的開場：
先進城補給，再決定往哪走。地城在 59 步之外。

而前四輪的試玩是**從那座地城的深處開始的** ——
難怪連通性看起來那麼怪（`docs/playtest/05` §3 那條來回穿梭的路線，
是從地城中段往外走才會遇到的形狀）。

## 6. 還沒做的

- **建角本身**還沒接進「新遊戲」：`-newgame` 只設隊伍共用欄位，
  五個角色仍然是出貨存檔那五個。`F1` 可以逐個換掉（`createui.go`
  就是覆寫槽位），但「開新遊戲 → 強制建五個角色」的流程還沒串。
- `+0x58`–`+0x5c` 那艘船之外，建角程式還寫了什麼沒逐一掃完
  （只掃了本篇列的那些欄位）。
