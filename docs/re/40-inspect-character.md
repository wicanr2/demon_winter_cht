# 40 — 檢視角色（紮營選單 Party）

`1000:33e8`。選單上叫 `Party`，字串卻是 **`Inspect character:`** ——
這一項是**攤開一個人的角色卡**，不是隊伍總覽。

---

## 1. 主線很短

```
33e8  清畫面
33ec  FUN_1990_179b(0, 5, 3)        ; 畫選人清單（模式 3）
33f4  印 ds:0x605 "Inspect character:"
33fb  sel = FUN_1990_179b(2, 5, 3)  ; 選人
      sel == 隊伍人數 → 離開
      sel >= 0 → FUN_278d_2f61(sel, 2)     ; ★ 顯示角色卡，模式 2
      sel <  0 → 走 §2 那條
```

`FUN_278d_2f61(角色, 模式)` 就是角色卡的顯示常式；模式 2 是螢幕。
`ds:0x600` 是同一組選單的 `Exit`。

---

## 2. `sel < 0` 那條：輸出到別的地方

```
3406  FUN_1990_179b(0, 5, 4) / sel2 = FUN_1990_179b(2, 5, 4)   ; 第二層選單（模式 4）
341a  [0x15e2] = 1
341f  sprintf(buf, ds:0x613, ...)   ; "Hour %d, Day %d in the Month of the %s"
3425  輸出 buf；成功才繼續
      輸出 ds:0x63f                 ; "%s followed in the footsteps of"
3435  if [0x514a] == 0 → [0x514a] = 2
      sel2 == 0xffff → 對每個人呼叫 FUN_278d_2f61(i, [0x514a])
      否則            → FUN_278d_2f61(sel2, [0x514a])
```

先印一行時間戳、再印一句傳記開頭，然後把角色卡送去 `[0x514a]` 指定的地方
（預設 2）。**看起來是「把角色卡印到印表機」** —— 1988 年的 SSI 遊戲常有這個功能，
`0xffff` 那條就是「全隊都印」。

**沒解**：`[0x514a]` 的值域與語意（2 是螢幕，其他值是什麼沒查）、
`FUN_1d9f_179b` 到底是輸出到哪裡。**本專案不實作這一條** ——
就算解出來也沒有印表機可接。

---

## 3. 本專案的實作範圍

`cmd/demonwinter/campparty.go`：紮營選單按 `P` → 選人 → 角色卡。

卡面內容是本專案自己排的（原版的版面在 `FUN_278d_2f61` 裡，沒讀）：
名字／種族／職業／等級、五項屬性、生命與法力、武器與護甲、
經驗值與下一級門檻、信仰與祈禱成功率、束縛等級、已學技能。
資料全部來自已經解出來的欄位，沒有一項是新解的。

在卡上按 ↑↓ 直接換人 —— 原版要退回選單再選一次。這是介面上的方便，
不影響規則。

實機驗收（`workplace/dump/persist/55-camp-party.png`）：Menhir 是
人類遊俠 3 級，技能顯示「劍術／狩獵」—— 與 `docs/re/26` §4b 記的
「起始隊伍只有遊俠 Menhir 的狩獵旗標是 1」對得上。

> 世界地圖上的 `P`（隊伍名冊）是本作自己加的摘要畫面，與這一項並存：
> 一個看全隊、一個看單人。原版沒有前者。
