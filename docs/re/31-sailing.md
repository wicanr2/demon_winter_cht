# 31 — 搭船航行

`docs/re/28` 解完船隻陣列，碼頭因此買得到船 —— 但船只是海上一個圖案，
上不去。這一篇補「怎麼上船、上船之後有什麼不一樣」。

---

## 1. 一個 byte 就是整個搭船狀態

隊伍欄位 **`+0xb0`：目前搭的是第幾艘船，存的是格號 +1，`0` 代表沒搭**。

`+1` 不是設計潔癖 —— `0` 要留給「沒搭船」，而 0 號格是合法的船位。

| 位址 | 做什麼 |
|---|---|
| `0x16ede` | 上船：`party[+0xb0] = 格號 + 1` |
| `0x16dd6` | 上岸：`party[+0xb0] = 0` |
| `0x1614b` | 每步讀它決定要不要同步船的位置 |
| `0x3c0a` | **`+0xb0 != 0` 時不播腳步聲** —— 船上不會有腳步聲 |

最後一條是那種「一看就知道判對了」的旁證：沒有人會為了別的用途，
在播腳步聲之前檢查這個欄位。

---

## 2. 上船：走到船那一格

移動判定裡有一段掃 10 個船位（`0x16e2b`–`0x16e7c`）：

```
16e41  cmpb $0, ship[+0x25]        ; 船體 0 → 空格，跳過
16e4b  ship.X → [bp-0x15]
16e52  ship.Y → [bp-0x16]
16e59  ship.MapID → [bp-0x17]
16e65  ship.X == 目標X ?
16e6f  ship.Y == 目標Y ?
16e77  ship.MapID == party[+0xa3] ?
16e7c  三者皆同 → 0x16ed7（上船）
```

上船之後：

```
16ede  party[+0xb0] = 格號 + 1
16ee6  地圖緩衝[目標格] = 0x14      ; 那一格的圖塊改回海面（船圖案移除）
```

**這一段要排在可通行性判定之前（或取代它）。** 船停在海上，而海面在
可通行性表裡是不可通行的 —— 照一般規則根本走不過去。本專案第一版
把上船判定放在 `blocked` 之後，結果是「船看得到、上不去」，
實機截圖直接抓到（`workplace/dump/persist/40-sail.png`：`前方無法通行`）。

`0x16ef6` 之後還有一段處理「船在相鄰子地圖」的情形
（`|ΔmapID| == 1` 且 `Y ± 0x38` 對得上），本專案沒實作 —— 跨子地圖上船。

---

## 3. 航行與上岸

搭著船的時候，**移動規則只變一條：海面變成可通行**。陸地照樣查可通行性表，
走得上去就是上岸。

上岸那一段（`0x16d60`–`0x16ddc`）把船的座標與子地圖寫回記錄，再清掉 `+0xb0`。
所以**船會停在你踏上岸的前一格海面上**，下次還在那裡。

`0x16dde` 之後那一段：目標格既不是 `0x14` 也不是 `0x62` 時播一個音效並
把某個回傳值設成 −2 —— 看起來是撞岸的提示音，本專案沒實作。

---

## 4. 兩個容易寫錯的地方

**兩個海面 tile 都要認。** `0x14` 與 `0x62` 是同一種地形的兩種浪花，
載入時隨機摻著鋪。只認一個的話，走到摻了另一種浪花的那一格會被當成
陸地而自動上岸 —— 在大海中央。

**上岸要把船寫回去。** 不寫的話船留在買它的地方，玩家開到對岸下船後
就再也找不到船了。

---

## 5. 本專案的實作範圍

- `internal/assets/scenario`：`SaveGame.Boat`（trailer `+0xb0`）雙向
- `internal/game/ship.go`：`IsOcean`／`BoatAt`／`Sailing`／`BoatIndex`／
  `BoatValue`／`StepBoat`
- `internal/game/move.go`：`Party.sailing` 讓海面可通行、
  `World.Boardable` 讓停著船的那一格可通行
- `cmd/demonwinter`：`stepBoat` 接在走完一步之後，訊息「登船」「上岸」

實機驗收（`-map 44 -x 39 -y 22`，原版存檔第 0 艘船就停在 (39,21)）：
往北一步登船 → 在海上走三步（座標 39,19、地形 20 = `0x14`）→ 折回岸邊上岸 →
存檔。與原版 `PARTY.DAT` 逐 byte 比對只差六個 byte：船的座標
`+0x22/+0x23` 從 (39,21) 變成 (38,22)（跟著隊伍走、停在下船處）、
隊伍座標與子地圖、步數計數。**`+0xb0` 不在差異裡** —— 上岸之後回到 0，
與原版一致。

**沒實作**：跨子地圖上船（§2 末）、撞岸音效、船體損耗（什麼時候掉血還沒追）。
