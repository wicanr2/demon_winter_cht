# 幻象輪到行動前的消失判定

## 問題

手冊只說幻象可能在任何回合消失，舊研究一直沒有找到確切機率。
`docs/re/06` 又曾把同一段程式誤認成吐息，並因忽略 `Roll` 的 1-based
回傳範圍而寫成 30%。

## 工具與輸入

- IDA Pro 9.4：`/home/anr2/ida_94_official/dist`
- IDA 資料庫：`workplace/ida/DEMON.INT.i64`
- 匯出組語：`workplace/ida/DEMON.INT.asm`
- 原始執行檔與雜湊沿用 `docs/re/00-ghidra-setup.md` 的已驗證基線

## 指令證據

戰鬥主迴圈 `sub_138D2` 在單位已走到自己的座標、但尚未派發 AI／玩家行動前，
執行以下分支：

```asm
138d:026d  cmp word ptr [bx+4ED4h], 3
138d:0272  jz  short 138d:027b
138d:0274  cmp word ptr [bx+4ED4h], 0Dh
138d:0279  jnz short 138d:02e7

138d:027b  mov ax, 0Ah
138d:027e  push ax
138d:027f  call 1d9f:0e0b       ; IDA 名稱 sub_1E7FB
138d:0284  pop cx
138d:0285  cmp ax, 3
138d:0288  jge short 138d:02e7
```

戰鬥單位 `+20h`（絕對位址 `DS:4ED4h`）已由 `internal/game/side.go` 所列的
寫入端與消費端證明是陣營：

- `3` = 敵方幻象；
- `13`（`0Dh`）= 玩家方幻象。

`sub_1E7FB` 的函式本體在 `1d9f:0E0B`：以 `uniform × n` 截斷後加一，
所以 `Roll(10)` 的值域是 **1–10**，不是 0–9。`cmp ax,3 / jge` 只讓
結果 1、2 進入消失分支，故機率是：

```text
2 / 10 = 20%
```

成功觸發後，程式用單位名稱格式化 `DS:06C2 "%s dies!"`，再於
`138d:02cf` 呼叫 `0990:5564`（IDA 名稱 `sub_15564`，參數
`0, slot, slot, 0`）；該函式接著走既有的死亡／移除與戰場重繪流程。
這排除了「吐息能力」與「只是跳過行動」兩種舊解釋。

## 行為解讀

**已證實：**

1. 敵我兩側的幻象都適用。
2. 每次輪到該幻象行動、派發正式動作之前擲一次。
3. `Roll(10) < 3`，即 20% 消失。
4. 消失走死亡清理；原版顯示 `%s dies!`。
5. 一般怪物、玩家、被附身者與真正的召喚物不消耗這次亂數。

這不是「每個整體回合開頭掃描全部幻象」。幻象若不在本回合行動佇列，
就不會憑空多擲一次；同一個行動也不能因畫面更新而重擲。

## remake 對應

- `internal/game.Battle.Current` 在首次取得該單位行動前執行判定。
- `turnCheckedFor` 保證呈現層每幀反覆查詢時只擲一次。
- `TakeVanished` 把一次性的消失事件交給 UI。
- UI 顯示「`%s 消散了`」，語意比直譯「死了」更符合繁中幻象敘述，
  規則與原版死亡清理不變。
- `BeginRound` 同時重設行動點擁有者；這也修正單一存活單位跨回合時
  沒有重新取得速度行動點的既有漏洞。

## 驗證

單元測試釘住：

- 邊界 `Roll(10)=2` 消失、`=3` 不消失；
- 同一行動重查 `Current` 不推進 RNG；
- 非幻象陣營不推進這次 RNG；
- 新回合重新取得行動點；
- 消失事件只可取一次。
