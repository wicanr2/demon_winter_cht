# 38 — 觀地（紮營選單 View land）

**這是原版唯一的「看地圖」手段。** 平常畫面上只有腳邊那 9×9，
爬上高處才能把視窗推開去看遠處 —— 而且整隊一天只能看一次。

`1000:097b`。

---

## 1. 三道門檻

```
選人；取消 → 離開
狀態(char+0x102) >= 2       → 印訊息，離開
char[+0xe2] == 0            → 印「你不會」[0x49]/[0x4b]
party[+0xac] == 1           → 印「今天做過了」[0x2]/[0x4]
party[+0xa3] <= 10          → 什麼都不做，直接離開
party[+0xac] = 1
```

三道門檻各有值得記的地方：

**`char+0xe2` 是技能 26**（旗標陣列從 `+0xc8` 起算）—— 技能表的第 26 項
就叫 `View land`，與這個選單項同名。這是 `docs/re/37` §2 那個交叉印證的第二例：
欄位位移從程式碼推、名稱從字串表切，兩邊在同一格對上。

**`party+0xac` 是隊伍層級的每日旗標。** 鑑定（`+0xed`）與打獵（`+0xef`）
是**每人各自一份**，觀地卻是**整隊共用一次** —— 三個旗標都由睡覺清掉
（`2aed:03e4` 那一段）。同一個「每日一次」的概念，作用範圍不同。

**`party[+0xa3] > 10` 才看得到。** 子地圖編號 10 以下是地城與室內。
這個分界與 `world.SubMapMinID`（= 11，世界格 (1,1) 的編號）完全一致 ——
那個常數是從 SUM.MAP 的結構推出來的，與這裡各自獨立。

狀態門檻是 `< 2`，比鑑定的 `< 3` 嚴一格：**中毒還能研究道具，但爬不上高處。**

## 2. 檢視本身

```
09f0  local_6/local_8 = party[+0xa1]/[+0xa2]      ; 起點就是隊伍所在的格子
0a0c  [0x4c86] = 0                                ; 光照內縮暫時關掉
0a15  local_10 = party[+0xa3] / 10
      local_12 = party[+0xa3] % 10
0a24  FUN_1000_0e0d(local_10, local_12)           ; 載入那一格的世界地圖
      迴圈 {
0a4a    FUN_222f_1404(x − 4, y − 4)               ; 畫 9×9 視窗
        讀鍵；方向鍵移動 x/y
      }
```

`mapID / 10` 與 `mapID % 10` 就是子地圖編號的欄與列
（`world.SubMapColumn`／`SubMapRow`，早就解出來了）。

`FUN_222f_1404(中心 − 4, 中心 − 4)` **與戰場攝影機是同一支常式**
（`docs/re/35` §4）—— 9×9 視窗、左上角 = 中心減四。看地圖與看戰場
共用同一個「捲動視窗」機制。

`[0x4c86] = 0` 那一行把光照內縮關掉：**觀地看得到的範圍不受天色影響**。
（那個變數屬於 `0x172f4` 那塊 9×9 緩衝，不是戰場 —— 見 `docs/re/36` §2。）

## 3. 本專案的實作範圍

- `internal/assets/scenario`：`SaveGame.ViewedLandToday`（trailer `+0xac`）雙向
- `internal/game/viewland.go`：`SkillViewLand`／`CanViewLand`／
  `ViewLandOrigin`／`ViewLandStep`
- `cmd/demonwinter/campviewland.go`：紮營選單按 `V`，方向鍵張望、Esc 下來
- 睡覺（紮營與旅店）清掉 `ViewedLandToday`

新增一個偵錯旗標 `-give-skill`：起始隊伍沒有人會觀地，也沒有人會三種學識，
那幾個紮營選項在 headless 驗收時一步都走不到。只動記憶體。

實機驗收（`workplace/dump/persist/53-camp-viewland.png`，
`-map 44 -x 30 -y 30 -give-skill 26`）：起點 (30,30)，按 ↑↑→→→ 之後
右欄顯示 (33,28)，地圖跟著捲動。沒給技能時五個人全部標「不會觀地」；
在地城裡（子地圖 < 11）則回「這裡看不到地形」。

**沒實作**：原版那個迴圈還處理了幾個非方向鍵的分支（`FUN_2cdc_033d(0x25d)`
的回傳值 0 以外的情形），沒讀。
