# 67 — 神殿後面的樓梯

`docs/re/66` §4 在神殿那張 9 格跳表裡撞到一句沒被記載過的話：

```
ds:0x324c  "The priest shows you to"
ds:0x3264  "a stairway in the back."
```

`docs/re/19`（神殿三項服務）與 `docs/re/29`（改宗）都沒提過它。
這一篇把去向讀出來。

---

## 1. 它是一道傳送門

```
1c04a   關掉輸入、清畫面
1c05a   印 "The priest shows you to"
1c067   印 "a stairway in the back."
1c081   party[+0xa1] = 0x16      ; X = 22
1c08b   party[+0xa2] = 0x15      ; Y = 21
1c095   party[+0xa3] = 0x01      ; 子地圖 1
1c09f   party[+0xa9] = 0         ; 清掉（語意未定）
1c0a8   retf
```

**直接寫座標，不檢查可通行性、不推進時間** —— 與 `docs/re/05` 的
`TeleportTo` 同一種寫法。

---

## 2. 目的地是起始地城

子地圖 `1` 就是 `MAP1.MAP`。而**起始存檔的隊伍就在子地圖 1**：

```
起始存檔  +0xa1 X = 9   +0xa2 Y = 32   +0xa3 子地圖 = 1
樓梯目的地      X = 22        Y = 21              1
```

同一張地圖的不同角落。所以這道樓梯是**從城鎮回到起始地城的捷徑**，
不是通往新區域 —— 這個判讀比「神殿藏著隱藏關卡」保守，
但符合座標證據。

> ⚠ 目的地 `(22, 21)` 那一格是什麼還沒查（要解 `MAP1.MAP` 對應位置的 tile）。
> 「捷徑」是依座標推的，不是從敘述讀的。

---

## 3. 觸發條件還沒讀

分派是 `sub ax,2 / cmp ax,9 / jmp cs:[bx+0xbeb]`，
所以 case 8 對應**選單選項編號 10**。

神殿那一帶的字串只有介面框（`The temple of %s`、`Welcome, my son`、`Choose:`），
**選項清單不在這一段** —— 應該是從 `FILES.DTT` 的某張表組出來的。
「選項 10 在什麼條件下出現」因此還沒讀。

`docs/re/19` §3 記的神殿只有三項（捐獻／祈禱／改宗），
這道樓梯是第四項 —— **那份清單需要補**。
