# 47 — 商隊購買介面，與一個被價格照出來的破洞

`docs/re/32` 讀完商隊怎麼生貨，結尾寫的是：

> **沒有遭遇畫面** —— 規則是完整且可測的，介面等價格公式解出來再做。

`docs/re/44`／`45`／`46` 把價格解到「`+0x0a` 為 0 就算得準」，
所以這一輪把畫面補上。介面本身沒什麼好記的，
真正值得寫下來的是**接上去之後才浮出來的兩件事**。

---

## 1. 全部的貨都標價 0

第一次跑起來，七件貨的開價一律是 0。

`MerchantPrice` 是乘法，`估價 = 底價 × 材質倍率`（`docs/re/44` §1），
所以只要材質倍率是 0，後面乘幾次都還是 0。往回查倍率表：

```
materialMultiplier = [0, 1, 2, 5, 20, 35, 50, 60, 75]
                      ↑ 類別 0 的倍率就是 0
```

而 `GenerateLoot` 從來沒寫過 `+0x0f`（材質類別）—— Go 的零值是 0，
剛好落在倍率 0 那一格。**不是估價公式錯，是掉寶生成器少填一個欄位。**

這個破洞在「只生貨、不標價」的時候完全看不出來：`docs/re/32`
那一輪的測試釘的是附魔、效果、詛咒，沒有一項會碰到 `+0x0f`。
價格是第一個讀這個欄位的消費者，一接上就把它照出來了。

> 這是 `rulebook/60` 的實例：**能區分對錯的訊號才有用**。
> 舊測試全綠，因為它們問的問題裡沒有一個的答案取決於 `+0x0f`。

### 暫時填 1，並且標明它是暫時的

原版填 `+0x0f` 的規則在 `1990:11b9`–`1228`，**還沒讀**。
現在填的是 1，依據是兩份原版存檔裡**每一件真道具的 `+0x0f` 都是 1**
（0 只出現在空槽）。倍率 1 = 原價，是保守的下界，不會憑空放大價格。

`internal/game/loot.go` 的註解把「這是暫填、真規則在哪」寫在原地，
不是寫在某份 TODO 清單裡 —— 免得下一輪把它當成已解的事實。

## 2. 價格量級沒有對照過

一支等級 12 的商隊，畫面上的開價長這樣：

| 貨 | 開價 |
|---|---|
| 晨星鎚 +1 | 14 |
| 寶石 +4 | 1893 |
| 藥瓶 | 65 |
| 匕首 | 2 |
| 鱗甲 | 196 |
| 魔杖 | 26803 |
| 短劍 | 17 |

跨度四個數量級。**這不必然是錯的** —— 材質倍率本來就到 75 倍，
強度加價又是平方項（`docs/re/46` §1），高等級的魔杖賣天價完全講得通。
但目前**沒有任何一個數字跟原版對過**。

在 DOSBox 裡開同一支商隊比對之前，這一欄只能當「公式跑得動」的證據，
不能當「公式對了」的證據（`rulebook/65`）。真要對照，`+0x0f`
必須先解出來 —— 否則對不上也分不清是估價錯還是材質類別填錯。

---

## 3. 介面的兩個判斷

**算不準的貨不賣。** `ItemValue` 會回報 `exact`；`+0x0a` 不為 0 的貨
（估價缺第四項，`docs/re/46` §3）在清單上顯示「說不出價」，按 Enter 也買不了。

湊一個數字給玩家看起來比較完整，但那是把「我們還沒讀懂」偽裝成
「這東西就值這麼多」。少一件貨可以買，比一個假價格誠實。

**進入鍵 `M` 是偵錯用的。** 原版什麼情況下會遇到商隊、規模與等級怎麼決定，
都還沒追（`docs/re/32` §4 的「遭遇觸發」）。與 `B 測試戰鬥`、`T 進入城鎮`
同一個性質：沒有這個鍵就沒辦法把畫面叫出來驗。

## 4. 本專案的實作範圍

- `internal/game/merchant.go`：`MerchantWare`（貨 + 開價 + 已售出）、
  `Merchant.Wares` 改帶價格、`BuyFromMerchant`。
  `RollMerchant` 裡**先標已鑑定再估價**，順序照原版 `0x1d6c8`（`docs/re/44` §2）。
- `internal/game/loot.go`：`MaterialClass` 暫填 1（見 §1）。
- `cmd/demonwinter/merchantui.go`：招呼／貨單／購買。
- `assets/lang/zh-Hant/merchant.txt`：七個形容詞的譯名
  （目錄以**規模**為索引 0–9，不是形容詞編號 —— 對照表在 `docs/re/32` §1）。

測試釘住：列出來的貨都是已鑑定且開價 > 0（就是 §1 那個破洞的迴歸測試）、
買成功會扣錢並進道具欄、以及四種拒絕（已售出／說不出價／錢不夠／道具欄滿）。
