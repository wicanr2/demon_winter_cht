## 2. 「不開打」的三條路（`0x1899c` 一帶）

這三處都在同一支函式，而且**都接著 `return 3`** —— 也就是
「這一步不開打」。它們不是把倒數重設得更久，是**把檢定推遲一步**：

```
1899c  ax = ds:0x50ee              ; Y 座標
1899f  if (ax == 4 || ax == 0x3b) {
189ad      party[+0x9c] = 1        ; 下一步再檢定
189b3      return 3
       }

189bb  if (ds:0x52d4 != 0 && party[+0xa3] < 9) {
189ce      party[+0x9c] = 10       ; 延後 10 步
189d4      return 3
       }

189eb  al = 查表結果
189f0  if (al == 0xff) {
189f9      party[+0x9c] = 1        ; 下一步再檢定
189ff      return 3
       }
```

### `= 1` 的兩處都是「這裡不適合開打」

- **Y == 4 或 0x3b(59)**：那正是 `docs/re/58` §2 跨子地圖時
  座標被 wrap 到的落點（`0x50ee = 4`／`0x50f0 = 0x3b`）。
  **剛跨過邊界的那一步不開打** —— 不然玩家會在地圖接縫上被伏擊。
- **查表得 `0xff`**：這一格沒有對應的遭遇群組（`docs/re/24` 的 18 個群組）。
  沒東西可挑就不開打。

兩處都設 `1` 而不是 `0`，因為 `0` 會讓下一步的 `dec` 變成 255（byte 下溢）。

### `= 10` 那處

`ds:0x52d4 != 0` 且 `+0xa3 < 9`（地城）→ 延後 10 步。

`ds:0x52d4` ＝ **子地圖巢狀深度**（`docs/re/76`，非 0 就是不在大地圖上）。
所以這一處是「**在室內且子地圖 < 9** → 遭遇倒數設 10」，
與 `docs/re/24` §58「船上不擲」是同一個變數的同一種用法。

## 3. 兩處待確認

### `Roll(50) + 150` ＝ 151–200（`0x106ff`）

所屬函式（`0x10580`–`0x10720`）唯一的字串是 `You:`。
151–200 步是**非常長**的一段安全期。

合理的猜測是商隊交易之後（`docs/re/50`／`51`：商隊是走路時 1/64 的事件），
交易完給一段長安全期避免立刻又遇上。**但 `You:` 不足以定案** ——
沒有追呼叫端，標為待確認。

### `Roll(5) + 14` ＝ 15–19（`0x14933`）

所屬函式無字串。範圍很短，像是某個小事件之後的短暫喘息。**未追。**
