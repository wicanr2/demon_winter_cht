# 42 — 戰鬥外施法（紮營選單 Cast）

紮營選單剩下的兩項（Worship 與 Cast）卡在同一個地方：**本專案的施法離不開戰場**。
`applySpell` 要 `battle.Kill`、要 `battle.UnitAt`，沒有 `*Battle` 就跑不起來。
這一篇把那個前提拆掉。

---

## 1. 原版沒有這個問題

原版的施法入口是 `FUN_1000_11e5(誰, 力度, 效果索引, 模式)`，
**戰鬥內外是同一支**：

| 呼叫端 | 參數 |
|---|---|
| 戰鬥中施法 | `(單位, 投入的 SP, 法術 id, ?)` |
| 紮營 Use（有效果的道具）| `(角色, 道具 +0x08, 道具 +0x07, 1)`（`docs/re/39`）|
| 紮營 Worship | `(角色, 300, 神祇的法術 id, 3)`（`docs/re/43` 待寫）|

效果記錄、力度公式、判定全部共用，差別只在第四個參數（語意未解）。
**「戰鬥外不能施法」是本專案自己造出來的限制**，不是原版的。

---

## 2. 哪些效果離得開戰場

拆的標準不是「哪些好做」，是**哪些在戰鬥外有意義**：

| 效果 | 營地 | 理由 |
|---|---|---|
| 生命（5）、法力（13）| ✅ | 作用在角色的持久欄位 |
| 解除束縛（10）| ✅ | 狀態欄是持久的 |
| 枯萎（14）| ✅ | 直接改屬性，持久 |
| 技巧（3）／力量（4）／速度（6）／護甲（7）増減 | ❌ | 改的是**戰鬥單位**的暫時值 |
| 範圍傷害（1）、即死（2）、施加束縛（11）| ❌ | 要戰場網格與勝負結算 |

第三列是重點：那四種增減在原版也是寫進戰鬥單位陣列（`0x4eb4` 起，
`docs/re/20` 的欄位表），**戰鬥一結束就沒了**。在營地放等於什麼都沒做 ——
與其讓玩家花法力買一個空氣，不如擋下來說清楚。

> 這是「照抄原版」與「照抄原版的**後果**」的分野。原版的選單大概真的讓你放，
> 然後什麼都不發生。本專案選擇說明理由 —— 規則沒有變寬也沒有變窄，
> 變的是玩家知不知道自己在做什麼。

---

## 3. 本專案的實作範圍

`internal/game/campcast.go`：`CampCastable`／`CampCast`／`CampCastCandidates`。

作法是**借一個戰鬥單位當計算載體**：效果函式（`CastMagnitudeEffect`、
`CastBindRelease`、`CastWither`）都吃 `*Unit`，而它們動到的欄位
（HP／SP／狀態）在 `Character` 上都有對應。算完只把那三項寫回去 ——
`writeBackFromUnit` 刻意不碰速度／力量／技巧／護甲，那正是 §2 擋掉四種效果的理由。

`cmd/demonwinter/campcast.go`：紮營選單按 `C`，四步
（施術者 → 法術 → 投入法力 → 目標）。法力預設就填法術的最低需求 `M`，
一按 Enter 就放得出來。

實機驗收（`workplace/dump/persist/57`／`58`）：清單列出 11 個放得出來的法術
（治療、生命之息、汲取法力、掙脫束縛、枯萎打擊…），
Wopple 對 Stumpy 放「烈焰之柱」造成 1 點傷害 —— **對自己人放攻擊法術是可以的**，
原版也沒攔。

**沒實作**：
- 施法選單不看技能。戰鬥中的選單也一樣（列出全部法術），是同一個坑。
- Worship（`1000:0ed0`）還缺一塊：它要查 `[0x4cc4]` 那張「神祇 → 法術 id」表，
  那是個執行期指標，還沒定位。規則其餘部分已讀完（見下）。

## 4. 順帶讀完的 Worship

`1000:0ed0`，規則已經清楚，只差那張表：

```
選人；狀態 >= 2 → 訊息
技能 15（薩滿）與 16（司祭）都沒有 → 「你不會」
char[+0xf1] != 0 → 「今天做過了」        ; 又一個每人每天一次的旗標
char[+0xf1] = 1
deity = char[+0xf0] − 1
spellID = [0x4cc4][deity × 2]
rnd(100) > char[+0xeb]（祈禱成功率）或 spellID == −1 → 失敗
成功：
  char[+0xeb] −= 5                      ; 與神殿祈禱同一個遞減
  spellID == −2 → spellID = rnd(11) + 0x1a   ; 隨機 27–37
  FUN_1000_11e5(誰, 300, spellID, 3)    ; ★ 力度固定 300
```

三件事值得先記下來：

- **力度固定 300**。一般施法的力度是玩家投入的 SP（個位到幾十），
  300 是完全不同的量級 —— 神祇出手就是壓倒性的。
- **成功率與神殿祈禱共用 `+0xeb`，遞減也一樣是 −5**（`docs/re/19` §3.3）。
  營地敬拜與戰鬥中呼喚神祇吃的是同一條額度。
- 表裡的 **−1 = 這位神祇不賜法術**、**−2 = 隨機挑一個**（27–37 那一段）。

缺的就是 `[0x4cc4]` 那 11 個 word。定位到它，Worship 就能接上。
