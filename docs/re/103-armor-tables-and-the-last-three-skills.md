# 103 — 護甲的兩張表，與 A9 最後三項「學得到但沒有效果」的技能

A9 是 worklist 上一條長期掛帳：**學院收得到錢、角色卡列得出技能，
但引擎沒有任何一處讀它**。這一輪把剩下的三項接完（12 幻術／13 附身／
14 召喚共用的施法閘門、30 硬化皮膚、精靈的察覺靈光），
而追硬化皮膚那 `+2` 的來源時，順帶把 `docs/re/06` §545 掛了很久的
「**裝備護甲最終數值表**（`31f0:16c5`）……表格內容本次未逐一核對」補完，
以及旁邊那張沒人注意過的**職業護甲上限表**。

## 1. 施法閘門：學了才施得出來

手冊 `part-3.md` 講的是介面行為：

> 按下「C」可施展法術。**角色學會的符文與吟唱法術會顯示在畫面底部。**

`part-2.md` 講為什麼要分系：

> 每種符文與吟唱法術都只有一間學院教授。附身、劍擊與功夫也都各自
> 只有獨一無二的學院。

引擎原本把 43 筆全列給每個人。後果不只是「選單太長」——
**技能 12/13/14/17–21 一共八項因此完全沒有效果**，
學院那條經濟線也跟著失去意義。

換算表不必反組譯就有：怪物 AI 那側早就實作過同一條
（`internal/game/aispell.go` 的 `aiSchoolSkill`，原版只對「被附身的
玩家角色」檢查）。兩邊共用同一個常數，避免抄成兩份會漂的實作。

吟唱那一系分不出來 —— 三筆的 `school` 都是 6，只能靠法術索引：

| 索引 | effect | 法術 | 技能 |
|---|---|---|---|
| 24 | 15 | 召喚 | 14 |
| 25 | 15 | 幻術 | 12 |
| 26 | 16 | 附身 | 13 |

**查不到系別時放行，不是擋下。** 表裡有幾筆佔位記錄，
「認不出所以不給施法」會把資料問題變成玩家看得見的缺功能。
召喚／幻術生出來的生物沒有角色記錄，那條路在呼叫端就跳過閘門。

實跑（`-seed=4`）：

- Stumpy（術士，技能 12+14）→ 選單只剩 **召喚／幻術**
- Wopple（巫師，技能 17 火焰符文 + 21 靈魂符文）→ 只剩火系與靈魂系
- 同一個 Wopple 加 `-give-skill=13` → 附身出現在清單中段

## 2. 硬化皮膚：`+0xe6` 不是盾牌旗標

護甲那段收尾在 `17c5:0bee`：

```
0bee  LES BX,[0x4c7e]
0bf2  CMP byte ptr ES:[BX + SI + 0xe6],0x0
0bf8  JZ   跳過
0bfa  INC  word ptr [BP + -0x2]
0bfd  INC  word ptr [BP + -0x2]      ; 護甲 += 2
0c00  ...                            ; 寫進 unit+0x0a
```

`SI = 角色序號 × 0x104`，所以 `+0xe6` 是**角色記錄的位移**。
技能旗標陣列從 `+0xc8` 起算 31 格（id 0–30），
`0xc8 + 30 = 0xe6` —— 那是**最後一格，技能 30 硬化皮膚**。

先前有兩份筆記讀錯同一個位移：

| 出處 | 原本寫的 | 問題 |
|---|---|---|
| `docs/re/06` 行 433 | 「再視**盾牌旗標** `+2`」 | 這遊戲的 `ITEMS.DAT` 三十件道具裡**沒有盾牌** |
| `docs/re/57` §4.2 | 「**逐件裝備累加**：檢查 `+0xe6`，成立就 `+= 2`」 | 那個檢查只跑一次，不在任何迴圈裡 |

手冊 `part-2.md` 對上了值：

> **硬化皮膚（Armored Skin）：** 讓角色擁有身經百戰戰士般堅韌的皮膚，
> 在原本穿著的護甲之外，**額外提供皮甲等級的防護**。

皮甲在下一節那張表裡正好是 **2**。技能加 2、皮甲 2 —— 兩邊自洽，
這同時反過來驗了那張表的位址讀對了。

「在原本穿著的護甲之外」也對得上程式順序：那個 `if` 在護甲計算之後、
**不在**「有穿護甲」的分支裡，所以赤手空拳也有 2 點。

## 3. 察覺靈光：精靈的天生能力

`0x0e454`–`0x0e498`，掛在戰鬥結算發戰利品那一段。

```
擲 Roll(9)
CX = 隊上精靈人數；CX += 4
Roll > CX → 不亮
否則看道具：
  槽[+0x02] != 0     附帶法術 A 的強度
  槽[+0x08] != 0     效果強度
  槽[+0x0a] != 0     特效值 A
  槽[+0x0e] != 10    附魔（存的是 +10 偏移）
四者任一成立 → 標上「偵測到靈光」
```

三件值得記的事：

1. **人數看種族不看技能旗標**（`0x0e259` 比的是 `+0xf5 == 1`）。
   察覺靈光是天生能力，不佔那 31 格。
2. **死人也算。** 那個計數在發經驗值的迴圈裡，`count++`（`0x0e261`）
   排在「戰鬥狀態 >= 2 就跳過」（`0x0e264`）之前。看起來像疏漏，
   但沒有旁證說它是 bug，照抄。
3. **沒查附帶法術 B 與特效值 B**（`+0x04`／`+0x0c`）。
   只長 B 那一組的道具偵測不到。照抄，不要補齊。

機率因此是 `Roll(9) <= 精靈人數 + 4`：一個精靈 **5/9**、五個精靈必中。
手冊那句「察覺靈光並非每次都能生效」就是這個。

順序上**先擲點再看道具**，所以隊上沒有精靈時**連骰都不擲** ——
這會影響 `-seed` 重跑的亂數序列，實作要照抄順序。

## 4. 護甲防護點數表（`31f0:16c5`）

`docs/re/06` §「護甲最終數值來源」把這張表列成「已驗證有此機制、
細節未解」，§545 掛成待辦。實際內容：

```
0x271c5:  00 01 02 04 05 06 03
```

索引 = `ITEMS.DAT 型別 − 7`（`17c5:0bb9` 的 `ADD AX,0xfff9`）：

| 型別 | 道具 | 防護 |
|---|---|---|
| 7 | 雙手劍 | 0（佔位，護甲槽放不進武器）|
| 8 | 布甲 | 1 |
| 9 | 皮甲 | 2 |
| 10 | 鎖子甲 | **4** |
| 11 | 鱗甲 | **5** |
| 12 | 板甲 | **6** |
| 13 | 王冠 | 3 |

**不是等差。** 引擎原本照手冊語感寫成「型別 − 7」的線性換算
（布 1 … 板 5），鎖子甲以上每件都少 1 點。老軟體的數字多半是表查出來的，
從觀察到的頭兩項推等差，會在第三項就開始錯。

計算全貌（`17c5:0b8a`–`0c18`）：

```
槽索引 = unit+0x0a         ; 0xff = 沒穿
0xff → 0 點
否則 型別 = 角色[槽×17 + 0xc]
     點數 = 表[型別 − 7] + (角色[槽×17 + 0x1a] − 10)   ; 後項是附魔
硬化皮膚 → 點數 += 2
點數 → unit+0x0a
```

**附魔直接加在點數上**，所以鎖子甲 +2 就等同板甲。
最終值印出來是 `Armor: %3d pts.`（`ds:0x0b15`），
戰鬥時 `0x9f4d` 從命中傷害裡直接減掉。

> ⚠ 手冊 `part-3.md` §護甲的舉例是「穿板甲的戰士若受到 7 點傷害，
> 護甲會吸收 5 點」—— 照這張表板甲是 6。手冊只在**同平台**時
> 壓過反組譯（`CONTEXT.md` §oracle 優先序，而手冊有部分章節寫的是
> Apple II 版），這裡以出貨的 DOS 資料為準，把差異記在這裡。

王冠（型別 13）有防護值 3 卻穿不上 —— 換裝那一段先擋型別範圍
（`1000:2820`／`1000:2825`：`< 8` 或 `> 12` 直接不理）。
表多一格是給邊界留的餘裕，不是隱藏機制。

## 5. 職業護甲上限表（`31f0:03de`）

換裝過了型別那一關還有第二關（`1000:282a`–`2846`）：

```
2832  AL = 角色[+0xf6]           ; 職業 id
2839  SHL AX,1                   ; × 2（word 表）
283d  CX = [BX + 0x3de]
2844  CMP CX,型別 ; JGE 放行
      否則印 ds:0x044a = "You're the wrong class."
```

```
0x25ede:  0e00 0c00 0c00 0900 0a00 0a00 0800 0800 0a00 0900
```

| 職業 id | 職業 | 上限型別 | 等於 |
|---|---|---|---|
| 0 | 遊俠 | 14 | 超出護甲型別上界，**實質不限** |
| 1 | 聖騎士 | 12 | 板甲 |
| 2 | 蠻族 | 12 | 板甲 |
| 3 | 武僧 | 9 | 皮甲 |
| 4 | 司祭 | 10 | 鎖子甲 |
| 5 | 盜賊 | 10 | 鎖子甲 |
| 6 | 巫師 | 8 | 布甲 |
| 7 | 術士 | 8 | 布甲 |
| 8 | 靈視者 | 10 | 鎖子甲 |
| 9 | 學者 | 9 | 皮甲 |

手冊 `part-1.md` 三處對得上，等於同時驗了表位址與職業排序：

| 手冊 | 表 |
|---|---|
| 「巫師被禁止穿著除**最輕型**以外的護甲」 | 巫師 8 布甲 ✅ |
| 靈視者「可穿著**重至鎖子甲**的護甲」 | 靈視者 10 鎖子甲 ✅ |
| 盜賊「不會穿著可能妨礙技能施展的**重型護甲**」 | 盜賊 10 鎖子甲 ✅ |

引擎原本完全沒有這道關 —— 巫師穿板甲、術士穿板甲都放行。
