# 88 — 建角寫進角色記錄的東西（`docs/re/87` §6 的收尾）

`docs/re/87` 只掃了 trailer 的隊伍共用欄位，結尾記著：

> 建好的角色狀態還沒與原版建角程式逐欄比對。……
> 現在的實作是「什麼都沒有」，那是**推論不是驗證**。

這一篇把它驗完。結論是實作對的 —— 但**理由與我原本的推論不同**，
而且順手釘死了一個容易讀錯的欄位長度。

---

## 1. 角色記錄的基底是 `ds:0x4c7e`，不是 `ds:0x4c76`

`ds:0x4c76` 是 **trailer** 的遠指標（全檔 425 處，`+0x9a` 人數、`+0xa1` 座標
那些都走它）。角色記錄走的是 **`ds:0x4c7e`**，步長 `0x104`：

```asm
mov ax,0x104
imul [bp-0x6]          ; ax = 角色索引 × 0x104
mov si,ax
les bx,ds:0x4c7e
mov byte es:[bx+si+0xf4],1     ; 等級 = 1
```

一開始找不到角色記錄的寫入端，是因為我去掃 `ds:0x548c`（arena 索引 0，
長度 1494 ＝ `PARTY.DAT` 大小）—— **全檔零命中**。
那個槽只有一處寫入、沒有任何 `les` 讀取，它不是實際用的指標。

## 2. 建角對角色記錄做的四件事

| 位址 | 動作 |
|---|---|
| `0x14dc5` | `+0xf4 = 1` —— **等級 1** |
| `0x150d1` | 迴圈十次：`inventory[i].Type = 0xff` —— **十格背包全部清空** |
| `0x150ed` | `+0x100 = 0xff` —— **裝備武器槽 ＝ 無** |
| `0x150ff` | `+0x101 = 0xff` —— **裝備護甲槽 ＝ 無** |

外加 trailer 那邊 `0x15109`：`inc trailer[+0x9a]` —— **每造一個角色，人數 +1**。

所以「新角色徒手、空背包、1 級」不是推論了，是四道寫入。

> **`docs/playtest/07` 修掉的那個 bug（新角色帶著十把匕首）方向是對的，
> 但當時的理由不完整。** 我當時只推「零值 `Type == 0` 是匕首，應該要是 `0xff`」；
> 原版確實明確寫 `0xff`，而且**還寫了兩個裝備槽索引**，那兩個我是靠
> 「合理」補上的。現在兩者都有指令依據。

### 順帶補上的：人數要跟著建好的數量走

原版是每造一個 `inc`，所以**還沒建角的隊伍是 0 人**。
`ApplyNewGame` 原本沒動 `PartySize`，留著出貨存檔的 5 ——
剛好對，但那是巧合：「建到一半就存檔」會寫出「5 人」而其中幾個
還是別人的角色，**讀回來完全看不出來**。現在歸零並隨建角遞增。

## 3. 兩處欄位複製，語意未解

`0x14d95`–`0x14db4`：

```
[+0xe8] = [+0xf8]
[+0xe9] = [+0xfb]
```

四個位移在 `save.go` 都不在已命名的清單裡。形狀像「目前值 ← 上限值」
那種配對，但**沒有讀取端的證據，所以不命名、不猜**。
引擎目前不寫這兩個 byte（留原值），與原版對新角色的行為有差 ——
記在這裡，等到找到讀取端再處理。

## 4. 一個差點誤報的「編碼器 bug」

驗存檔的時候我用 Python 讀 `PARTY.DAT`，道具槽的步長寫成 **16**，
結果看到「只有第 0 格是 `0xff`，其餘都留著出貨的值」——
一度以為存檔編碼器沒辦法表達「這一格變成空的」。

**道具槽長度是 17（`inventorySlotLen = 17`）。** 換成 17 之後，
五個角色五十格全部是 `0xff`，編碼器沒問題。

而 17 這個數字**原版的迴圈自己就寫著**：

```asm
mov ax,[bp-0x2]     ; i
mov cl,4
shl ax,cl           ; i × 16
add ax,dx           ; + i        → i × 17
```

`shl 4` 之後那個 `add ax,dx` 就是把 16 補成 17。
只看 `shl 4` 會以為步長是 16 —— 我在 Python 那邊犯的正是這個錯。

> 教訓不是「小心算術」，是**別在第二個地方重寫一次布局常數**。
> `inventorySlotLen` 在 Go 那邊是對的；我為了看一眼存檔在 Python 裡
> 抄了一份布局，抄錯了。跟 `tools/route.py` 那次（地圖檔頭偏移）
> 是同一種錯，同一種解法：**去問已經對的那一份**。
