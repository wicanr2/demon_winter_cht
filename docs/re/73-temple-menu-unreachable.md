# 73 — 神殿樓梯在這條路上到不了

`docs/re/67` 解出神殿樓梯的去向（傳送到子地圖 1 的 `(22,21)`），
但觸發條件一直沒解。`docs/re/67` §3 改過一次（樓梯不是第四個選單項），
這一篇把它追到底。

---

## 1. 回傳值 ＝ 選項索引 × 2 + 2

通用選單常式 `2cdc:033d` 的四個參數（C 是右到左推，最後 push 的是第一個）：

```
1bfeb  push ds / 0x3159   ; 參數 1：選項文字表（三筆 far ptr）
1bfe6  push ds / 0x3172   ; 參數 2
1bfe1  push ds / 0x316d   ; 參數 3："DPC"
1bfdd  push 2             ; 參數 4
1bff0  call 1cdc:033d
```

三張表的內容：

```
ds:0x3159  92 31 f0 21 | 9c 31 f0 21 | a1 31 f0 21 | 00 00 00 00 00 00 00 00
           → "Donations"    "Pray"       "Convert"    ← 8 bytes 全 0 ＝ 表結束
ds:0x316d  "DPC"
ds:0x3172  fe ff fe ff 01 00 fe ff 01 00 …           ← −2, −2, 1, −2, 1 …
```

對照跳表的目標就解出映射：

| 選項 | 索引 | 回傳 | case | 目標 |
|---|---|---|---|---|
| Donations | 0 | 2 | 0 | `0x1c031` |
| Pray | 1 | 4 | 2 | `0x1c039` |
| Convert | 2 | **6** | 4 | `0x1c020` → **`278d:0f38`**（`docs/re/29` 的改宗）|

**回傳值 ＝ 索引 × 2 + 2**，而 Convert → 6 → 改宗，三方對得起來。

---

## 2. 所以 case 6 與 case 8 到不了

跳表是 `sub ax,2 / cmp ax,9`，共 9 格（回傳 2–10）。但：

| 回傳 | case | 需要的選項索引 | 選單裡有嗎 |
|---|---|---|---|
| 8 | 6 | 3 | **沒有** |
| **10** | **8** | **4** | **沒有** |

選項文字表只有三筆（第四筆起是 8 bytes 的 0）。
兩個呼叫端也都**不傳表** —— 表寫死在函式內：

```
191ae  cmp ds:0x52f4, 0x25 / jne  → call 178d:0932    ; 走地圖進來
1bcfc  （城鎮設施分派）            → call 178d:0932
```

掃過 `ds:0x3159` 也沒有寫入端（不像 `T2C.TXT` 那樣被就地改寫，
`docs/re/70`）。所以：

**在神殿這條路上，樓梯（case 8）與 case 6 永遠到不了。**

`0x1c00d` 那道閘門（`回傳 == 8 && ds:0x5d48 == 0` → 退回選單）
因此也是遺留碼 —— 它守的那一格叫不出來。

## 3. 這是第三個「資料在、路徑沒接」

| 東西 | 情況 | 出處 |
|---|---|---|
| `TITLE.PIC` | 檔名表列著，檔案不在 dump 裡 | `title.go` |
| `OPEN.PIE` | 檔案在，檔名零命中 | `title.go` |
| `EREGORE.TXT`／`T.TXT` | 檔名與指標表都在，沒有讀取端 | `docs/re/71` |
| **神殿樓梯 + case 6** | 程式碼完整，選單給不出那個回傳值 | 本篇 |

四個都指向同一件事：**這份 1988 年的執行檔裡有開發途中留下的東西。**

樓梯那段程式碼是完整可執行的（印兩句話、寫四個欄位），
不是半成品 —— 它只是沒有入口。合理的猜測是原本規劃過
「神殿有第四項服務」，後來從選單裡撤掉但函式沒刪。
**這是判讀**；「選單給不出回傳 10」則是掃出來的。

## 4. 順帶：tile → 城鎮設施

`0x191ae` 一帶是 tile 分派：

```
191a7  cmp ds:0x52f4, 0x25 → call 178d:0932   ; 神殿
191b3  cmp ds:0x52f4, 0x26 → call 178d:11bd   ; 另一個設施（未查）
```

`docs/re/58` §2 只知道回傳碼 `0x13` 的觸發 tile 集合是
`{0x2e, 0x25, 0x26, 0x64, 0x5b}`，沒分辨哪個 tile 對哪個地點。
現在多兩筆：**`0x25` ＝ 神殿**、`0x26` ＝ `278d:11bd`（待查）。

`0x2e`／`0x64` 早就知道是城鎮（`docs/re/19` 的 25 筆座標表），
剩 `0x5b` 未知。
