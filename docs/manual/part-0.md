## 瑕疵磁片處理（What To Do If You Have A Defective Disk）

我們每一款遊戲在發行前都會經過大量的實機測試。透過這個過程，我們希望找出並修正程式中的錯誤。然而，由於模擬遊戲本身的複雜性，部分程式錯誤可能要到發行後才會被發現。除了程式本身的錯誤之外，磁片本體偶爾也會出問題。以壓片業界的一般水準來說，複製磁片約有 3% 至 5% 的故障率。在認定磁片有瑕疵之前，請先確認磁碟機是否正常。我們收到並被認定為「瑕疵」而退回的磁片中，有高達 95% 在我們的電腦系統上都能正常運作——問題通常出在磁碟機本身需要校正、調速或清潔保養。

若您的磁片確實有瑕疵，請只將磁片寄回（遊戲的其他部分請自行留存）給我們的客戶服務部門，並附上一份說明所遇到問題的字條。我們收到瑕疵磁片後，將提供替換磁片。

若您發現程式本身有錯誤，請將遊戲磁片與所有「存檔」磁片一併寄回我們的客戶服務部門，並附上錯誤發生當下遊戲進行狀況的說明。程式錯誤修正後，我們會將更新後的磁片寄還給您。

任何通信都請務必附上您的姓名、地址與白天可聯絡的電話號碼。我們會盡力讓所有問題儘快獲得解決。
