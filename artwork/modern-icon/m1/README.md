# Modern Icon M1：高解析世界地圖呈現層試驗

這裡驗證 Modern Icon 可在 `1280×800` 最終畫布直接覆寫地圖格，規則層仍使用
原版索引、碰撞與事件。loader 只接受逐索引列出的 `64×56` 不透明 PNG，並明確
拒絕舊的 `32×28` runtime trial。

`masters/` 保留依核准 concept 逐格重新構圖的母稿，不是從 contact sheet 裁切。
第一張森林曾刻意掛在大量出現的 `0x23` 上，只為證明高解析覆寫位置、裁切與
F8 管線；它不是平原索引的正式美術。實際索引盤點完成後，trial 已改為：

- `0x14`：深海；
- `0x17`：本場景左海右陸岸線；
- `0x23`：平原。

`0x17` 及同組 `0x1a/1d/20/3b/3c/3d/3e` 均有常態與冬季一一對應版本；
冬季只改積雪、色溫與水面材質，不改岸線方向、海陸比例或索引語意。

第二種海面浪紋 `0x62` 也使用獨立母稿，正常／冬季均可與 `0x14` 混鋪；沒有
用同一張海面重複填兩個索引，避免大面積海域形成棋盤重複。

本批可在 `demonwinter-go` 容器內以 `rebuild-coasts.sh` 重建；腳本同時執行
曲線化岸線、`0x62` 母稿匯出與 8 像素邊緣錨定，避免只靠文件記住手動步驟。

世界隊伍四向兩步由 `rebuild-party.sh` 重建：南 `0x18/19`、東 `0x1b/1c`、
北 `0x1e/1f`、西 `0x21/22`。西向是東向的精確鏡射，四向都維持透明 overlay，
先畫腳下真實地形再疊角色，不把黑底寫回地圖格。
同一腳本亦由北向船隻母圖精確旋轉出航海四向：北 `0x3f`、東 `0x40`、
南 `0x41`、西 `0x42`；船沒有兩步相位。

戰鬥呈現層也由 manifest 的 `battleSprites` 逐 frame 漸進覆寫：

- `combat`：玩家職業／面向 frame；首張 `0x1a` 使用西向透明隊伍角色；
- `monsters`：怪物外觀組的八幀空間；首張 `0x8d` 是預設測試戰鬥中朝東的 Orc；
- `ships`：海戰的 32 幀空間；`0x00–0x07` 先完成玩家船四向，兩個回合相位
  共用同方向素材。

未列出的 frame 保留相容底稿，不拿錯誤角色填滿清單。執行期會先重畫該格真實
戰場地形／海面，再疊透明單位並重畫選取框，所以不會留下舊 sprite 的黑底。

高地批次先完成雙倍移動成本的丘陵 `0x0e/0x2b`：前者是西南—東北的三道窄脊，
後者是反向的寬丘肩與草地鞍部。兩格各有構圖配對的正常／冬季版，每個索引再
輸出四張共用邊界的變體，由 `rebuild-highlands.sh` 重建。執行期只依世界座標
挑選變體，不使用遊戲 RNG；因此 F8、存檔及重播狀態不會被美術選圖改變，也不會
把同一張山圖掛到兩個交錯索引形成棋盤。

高山／岩地 `0x0f/0x10` 沿用相同契約：`0x0f` 是尖峰雙脊，`0x10` 是寬岩台、
斷崖與隘口；正常／冬季每索引各四變體。它們與丘陵分批建立共用邊界，避免把
高山的深色邊緣污染到較低的丘陵素材。

透明母圖使用共用 `remove_chroma_key.py`，所需 Pillow 已固定在本目錄 Dockerfile：

```bash
docker build --memory 1g -t demonwinter-art:modern-icon artwork/modern-icon
docker run --rm --network none --memory 512m --cpus 1 --pids-limit 128 \
  -u "$(id -u):$(id -g)" -v "$PWD:/work" -w /work \
  demonwinter-art:modern-icon bash artwork/modern-icon/m1/rebuild-party.sh
```

後續同一管線加入兩組獨立地表：

- `0x43–0x4a`：金赭沙地海岸，冬季仍保留風蝕沙紋；
- `0x4b–0x52`：濃密森林海岸，冬季改為覆雪灌木與裸枝。

純沙地 `0x28` 直接使用同一正常／冬季底材；森林海岸不拿單棵樹或
`normal-woodland-0b.png` 冒充滿版森林，而有自己的連續冠層母稿。
森林島內陸 `0x27` 也使用這份冠層底材；它在遭遇規則表被歸到平原類，但原版
圖像與實際 `map 13` 場景明確是森林紋理，視覺裁決不能被規則分類覆蓋。

世界特殊入口已分四種語意重畫：

- `0x25`：完整運作的石造神殿，與 `0x5b` 毀壞神殿保持明確前後關係；
- `0x26`：青綠穹頂與雙塔的魔法學院；
- `0x2e`：一般紅瓦圍牆城鎮；
- `0x64`：唯一使用此索引的 Asaht，改為金赭平頂沙漠城。
- `0x63`：三處主線緋紅符印；以中央裂紋符石與低矮環形基座呈現，不與山峰、
  碼頭、城鎮或傳送門混用。

五者均有構圖配對的正常／冬季版本，不能互換或以一張「城鎮」圖概括。

先前工作表所稱的「碼頭地形」是誤標：碼頭是城鎮資料內的設施，世界圖塊集中
沒有獨立碼頭索引。海上可見的對應素材是 `0x3f–0x42` 四向船隻 glyph，應列在
隊伍／船隻圖示批次，不得憑空新增一個地形索引。

八格均由 `tools/moderncoast` 重建；較早的 `normal-coast-17.png` 母稿保留為
方向紀錄，但執行期 `0x17` 已和其餘七格走同一管線，以免材質形成方形接縫。
原版 EGA 只提供水陸拓樸遮罩，工具會將 32×28 階梯輪廓曲線化，再以
Modern Icon 的草原、雪原與海面重新合成岸緣。它不是把原版 tile 或 concept
downscale；若輸出仍看得到階梯邊，contact-sheet 閘門就不接受。

第一批實際樹木索引已逐格裁決並加入 manifest：

- `0x04`：單株古樹；
- `0x07`：前後錯落的雙樹；
- `0x0b`：低矮林緣、幼樹與灌木帶。

三者均有正常／冬季配對母稿；舊的 `normal-forest.png` 仍只保留作為早期方向
紀錄，不再由 manifest 載入，也不代表任何正式索引。

劇情特殊格 `0x5b` 亦已加入：它是冬之魔降臨後由神殿替換成的毀壞廢墟，不是
一般岩石或城鎮。正常／冬季版本保留同一組殘牆、折柱與中央燒灼空洞。

以 `-modern-icon-dir artwork/modern-icon/m1/trial` 載入。未列出的格不會被舊圖
冒充 Modern Icon，而是保留底下的相容預覽，直到每個索引真正重畫並通過同場景
審核。後續仍須依實際 atlas 索引分別重畫其餘岸線方向、城鎮、特殊地標及隊伍
方向，不能把同一張圖掛到不同語意。
